# VideoClip

手機瀏覽器用的影片剪輯網頁 App（規劃中）。

- 公開網址、免登入；每台裝置的剪輯專案各自獨立，分享網址不會看到別人的專案
- 多專案管理、多影片拼接、多圖層疊加
- 豐富字卡（模板、繁體字體、字塊、裝飾、雲朵字、逐字動畫）
- 轉場與特效、調色、在影片上繪畫、自由剪裁（VLOG 人頭 O 效果）
- 匯出 1080×1920 MP4、IG 音源推薦、Google Drive 備份
