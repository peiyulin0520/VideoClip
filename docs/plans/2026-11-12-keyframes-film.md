# 修改規劃：關鍵影格（讓物件照自己調的方向移動）＋膠卷外框＋膠卷捲動

- 來源：使用者 2026-11-12 16:43，傳了 7 張截圖，是**剪映的膠卷特效教學**（照順序看），原話：「給你上一個剪映的膠卷特效教學，他有關鍵幀可以讓影片按照自己調整的方向移動按照圖片順序看，最後一張是膠卷樣式」。
- **截圖是第三方 App 的畫面，不放進 repo**（規則），以下用文字記下教學的步驟：
  1. 影片放進畫面，選「縮放」把影片縮到 **50%**。
  2. 在影片**開頭**按「◇＋」打一個**關鍵影格**（時間軸片段上出現紅色菱形）。
  3. 把影片拖到畫面**右下角外面**一點（位置 X 250、Y 742）。
  4. 播放頭移到**結尾**，把影片往上拖**出畫面上方**（Y −514）——這時自動多一個關鍵影格。
  5. 播放：影片從下往上**滾過畫面**（中間經過 Y 282、−32 等位置）。
  6. 最後一張：每段影片外面套一個**底片框**（像掃描的負片：深色細邊、邊上有小字「底片型號＋格數」、邊緣微紅），幾段接起來往上捲＝**膠卷捲動**的效果。
- 狀態：**規劃完成，尚未實作**（Opus 規劃，Sonnet 實作）。這份就是 `docs/LAYOUTS.md` 的 **L2（物件動畫核心）**＋部分 **L3（膠卷捲動）**。
- **建議順序**：**K1 關鍵影格核心 → K2 一鍵動畫預設（捲過畫面等）→ K3 膠卷外框樣式 → K4 一鍵「膠卷捲動」**。K1 做完就能照剪映教學的步驟手動做出來；K2～K4 是讓它一鍵完成。

## K1. 關鍵影格核心（任何疊加影片、照片、貼圖、文字都能用）

### 資料
- `ItemBase.keyframes?: Keyframe[]`（照時間排序）
  `Keyframe = { t: number /* 物件開始後幾秒 */; x: number; y: number; scale: number; rotation: number; opacity: number; ease?: 'linear' | 'ease' }`
- 沒有 `keyframes`（或少於 1 個）＝跟現在一樣，用 `transform`。
- 有關鍵影格時：`transform` 當作「沒動畫時的值」保留；畫面上用的是依時間內插的值。

### 計算（`src/engine/keyframes.ts`，純函式＋單元測試）
- `transformAt(item, t): Transform`：`local = t − item.start`；在第一個之前＝第一個的值，最後一個之後＝最後一個的值，中間依兩個關鍵影格線性內插（`ease` 時用 smoothstep）。旋轉照數字內插（不繞最短路）。
- `withTimeTransform(item, t)`：回傳 transform 換成 `transformAt` 的物件（給 scene／selection 用）。
- `upsertKeyframe(item, local, values)`：同一時間（±1/30 秒）就更新，不然插入並排序。
- `removeKeyframe(item, index)`。
- 分割物件（`splitFree`）時關鍵影格依切點分到兩段（前段保留 `< local` 的、後段平移時間；切點各補一個內插值）；修剪頭端時平移 `t`；變速不用處理（`t` 是時間軸秒數）。

### 用到 transform 的地方都要改成「這個時間的 transform」
- `engine/scene.ts` `buildScene(project, t, …)`：每個圖層先 `withTimeTransform(item, t)` 再 `toLayer`（預覽、單格輸出、整支匯出都走這裡 → 三者一致）。
- `app/editor/Preview.tsx`：選取框、觸控區、吸附用 `selectionBox(withTimeTransform(item, time))`（Preview 已經訂閱播放時間）。
- 拖移／雙指縮放旋轉、圖層分頁滑桿（`setTransform`）：**物件有關鍵影格時**，改的是「播放頭這個時間」的關鍵影格（沒有就新增一個）——剪映的行為：打過第一個關鍵影格後，換時間再拖，就自動多一個。沒有關鍵影格時照舊改 `transform`。實作：`setTransform(id, patch)` 裡判斷 `item.keyframes?.length`，有就 `upsertKeyframe(item, playhead − start, {...transformAt, ...patch})`。
- 裁切模式（`cropStore.startCrop`）以「播放頭這個時間的 transform」當起點；完成時寫回同一個關鍵影格（有的話）。

### 介面
- **播放列加「◇」按鈕**（跟剪映一樣在播放鍵旁邊）：選到物件時才亮。
  - 播放頭這個時間**沒有**關鍵影格 → 「◇＋」新增（值＝目前畫面上的位置）。
  - **有** → 變成實心「◆−」，按了刪除這個關鍵影格。
- **時間軸片段上畫小菱形**（物件開始後 `t` 的位置）；點菱形＝播放頭跳過去並選取物件。
- 「圖層」分頁的位置／大小／旋轉／透明度滑桿在有關鍵影格時標示「（關鍵影格）」，改的是播放頭的那一個；另外加「X 位置」「Y 位置」兩個滑桿（剪映有，用數字精準調；範圍 −50%～150%，可以放到畫面外）。
- 每個關鍵影格可以選「等速／緩入緩出」（點菱形後在面板切換）。
- 「清除全部關鍵影格」按鈕（一步復原）。

### 驗收
- 單元：內插（開頭前、中間、結尾後、等速與緩動、旋轉）、upsert 同時間合併、分割與修剪後關鍵影格位置正確。
- e2e：疊加一支影片 → 縮放 50% → 開頭按「◇＋」→ 拖到右下 → 播放頭移到結尾 → 往上拖出畫面（自動多一個）→ 時間軸上有 2 個菱形 → 在中間時間取樣，物件在兩者之間的位置；單格輸出同一時間位置一樣；整支匯出讀回中間一格位置一樣；刪除關鍵影格、清除全部、一步復原。
- 🔴 真機：拖拉打關鍵影格順不順。

## K2. 自己模擬素材之後的移動方式（使用者 2026-11-12 修正：不是固定的預設動畫）

> 使用者原話：「K2 應該是我打好影格後，可以自己模擬這個素材之後移動的方式」。
> 解讀：打好關鍵影格後，要能**看到、試播、直接調整**這個素材接下來會怎麼移動；另外提供「用手指拖一次就錄下移動路線」的方式。固定的預設動畫（捲過畫面等）降為附加的捷徑（K2d，可以之後再做）。

### K2a 移動路線預覽（打好關鍵影格就看得到）
- 選到有關鍵影格的物件時，預覽上畫出**移動路線**：一條虛線連起每個關鍵影格的位置（中間依內插取樣，緩入緩出時是曲線的疏密），每個關鍵影格一個**圓點**，標上順序（1、2、3…）與時間（0.0s、4.9s），線上有小箭頭表示方向。
- 播放頭所在的位置畫一個空心框（＝物件現在會在哪），拖時間軸時跟著沿路線移動。
- 物件在畫面外的部分也要看得到路線：預覽四周留一圈淡淡的「畫面外」區域（裁切模式也用得到），超出的路線畫在那裡。

### K2b 試播（模擬）
- 「試播移動」按鈕：只在這個物件的時間範圍內循環播放（其他圖層照常顯示），讓使用者看路線對不對；再按一次停止。
- 試播時可以選「0.5×／1×」速度。

### K2c 直接在路線上調整
- **拖路線上的圓點**＝改那個關鍵影格的位置（一步復原）。
- **點兩個圓點之間的線**＝在那裡加一個新的關鍵影格（時間依點的位置內插），可以把直線拉成彎的路線。
- 長按圓點：刪除這個關鍵影格／切換「等速／緩入緩出」／跳到那個時間。

### K2e 手指錄製路線（選用，K2a～c 做完再做）
- 「錄製移動」：按下後播放開始，使用者用手指拖著物件走，放開或物件時間結束就停止；每 0.1 秒記一個位置，結束後簡化成少數幾個關鍵影格（保留轉彎處），可以一步復原。

### K2d 常用動作捷徑（之後）
- 由下往上捲過畫面（教學那個）、由右往左、滑入、淡入淡出：按一下自動打好關鍵影格，之後一樣可以用 K2c 調整。

### 驗收
- 單元：路線取樣（等速／緩動）、點線段插入關鍵影格的時間與位置、拖點更新、錄製路線的簡化（直線段只留頭尾、轉彎保留）。
- e2e：打 3 個關鍵影格 → 預覽上有路線與 3 個圓點（位置對）→ 拖第 2 個圓點 → 關鍵影格位置改變、一步復原 → 點線段中間加一個 → 試播：物件在範圍內循環、取樣位置隨時間沿路線改變。
- 🔴 真機：圓點好不好抓、路線看不看得清楚。

## K3. 膠卷外框樣式（最後一張截圖的樣子）

- 每個影片／照片物件可以選「外框樣式」：**無／底片框／拍立得框／圓角白框**。
- **底片框**：物件外圍一圈細邊，上下邊有小字。使用者 2026-11-12 決定：
  - **字＝日期＋假的底片型號**：預設是今天的日期（例 `2026.11.12`）＋一個假型號（從幾個選：`VC 400`、`VC GOLD 200`、`VC PORTRAIT 160`、`VC MONO 400`），另外右下角小格數（24、24A…依物件順序）。日期與型號都可以改（日期可改成任何文字）。⚠ **不要用真實品牌字樣（例如 KODAK）**——商標。
  - **顏色不限黑色**：框的顏色用共用的 `ColorPicker`（含自訂顏色彈窗）；預設幾個：深紅棕（截圖那種）、黑、白、奶茶、粉、薄荷綠。字的顏色依框的深淺自動選（深框配暖橘字、淺框配深色字），也可以自己改。
- 畫法：合成器在物件外圍畫一張「框」貼圖（`compositor.ts`，跟現在的外框 `outline` 同一個位置，但用一張 canvas 畫的框圖），跟著物件移動、縮放、旋轉、關鍵影格；方框（選取、觸控）加上框的寬度。預覽、匯出共用。
- 資料：`ItemBase.frame?: { style: 'film' | 'polaroid' | 'white'; color: string; textColor?: string; date?: string; model?: string }`（沒有 `date`＝加外框那天的日期，存成文字，之後不會自己變）。
- 驗收：單元（框的寬度、方框變大多少）；e2e 套底片框 → 物件邊緣取樣是框的顏色、框裡面是影片；匯出單格一樣；截圖。

## K4. 一鍵「膠卷捲動」（把好幾段影片接成一條往上捲的膠卷）

- 「版型」選單加一個 **膠卷捲動**：選好幾支影片／照片 →
  - 每一段變成一個疊加物件，套 **底片框**、縮放到畫面寬度約 70%、置中；
  - 全部用**同一個速度**往上捲（每個物件各自的關鍵影格：起點在畫面下方外、依序往下排一格的距離，終點往上同樣的距離），看起來像一整條膠卷捲過畫面；
  - 時間：整條捲完的時間 = 素材數 × 每格停留秒數（預設 2 秒，可以調）；
  - 同一個 `group`，「移除版型」一次拿掉。
- 也可以選「橫向（往左捲）」。
- 這也順便解決 `LAYOUTS.md` L3 的「膠卷捲動」；拍貼機的「閃白出現」、依序滑入用 K2 的預設＋延遲另外做（之後）。
- 驗收：3 段影片 → 某個時間點取樣，畫面裡看得到 2 段、位置依序相差一格；結束時都在畫面外上方；匯出一致。
