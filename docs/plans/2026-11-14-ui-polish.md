# 播放列按鈕加中文、時間軸影像軌變矮（U1–U2）— 2026-11-14

  2. 「圖二播放軸影像太高了，縮圖可以再窄一些。」（圖二是我們的時間軸：最下面那條影像軌比其他軌高很多、縮圖很寬。）

## U1. 播放列：每個按鈕「圖示在上、中文在下」
- 現在（`src/app/pages/Editor.tsx` 的 `.playbar`）：播放鍵、縮小、放大只有圖示；「定位」是圖示跟字並排。
- 改成跟圖一一樣，每個按鈕都是**上面圖示（20px）、下面一行中文（12px）**：

  | 按鈕 | 圖示 | 中文 | aria-label（不變，e2e 用） |
  |---|---|---|---|
  | 播放／暫停 | ▶／❚❚ | 播放／暫停 | 播放／暫停 |
  | 定位 | ◇（有定位時 ◆、主題色） | 定位 | 在這個時間新增定位／刪除這個時間的定位 |
  | 縮小時間軸 | 放大鏡 − | 縮小 | 縮小時間軸 |
  | 放大時間軸 | 放大鏡 ＋ | 放大 | 放大時間軸 |

- 時間顯示（`0:00.0 / 1:55.7`）放在播放鍵右邊，窄的時候自動折成兩行（像圖一）。
- 新增共用元件 `PlaybarButton({ icon, label, ariaLabel, ... })`（`src/app/editor/PlaybarButton.tsx`）：`.pb-btn`＝直排、寬至少 48px、高 50px、圓角、底色同現在的 icon-btn；`KeyframeButton` 改用它。
- `--playbar-h` 從 52px 改 58px（放得下兩行）；預覽高度的計算已經用這個變數，會自動跟著。
- 驗收：e2e 截圖（390 寬）四個按鈕都有中文、不擠、不換行；既有用 `getByRole('button', { name: '播放' })`、`'縮小時間軸'` 的測試照舊過（aria-label 不變；按鈕內文字跟 aria-label 一樣或 aria-label 優先）。

## U2. 時間軸：影像軌變矮、縮圖變窄
- 現在（`src/app/editor/Timeline.tsx`）：最下面那條影像軌 `BASE_H = 44`、其他軌 `ROW_H = 32`；縮圖格寬 `max(h × 寬高比, 30)`，直式影片在 44 高時每格約 30px 寬。
- 改成：
  - `BASE_H` 44 → **32**（跟其他軌一樣高）；`ROW_H` 不變 32。
  - 縮圖格最窄 30px → **18px**（直式影片 32 高 × 0.5625 ≈ 18px，一格就是一張完整的直式縮圖，不會被裁成寬的）。橫式影片照比例（約 57px）。
  - 片段名稱改**一行**：「1 影片 90.6s」（序號＋名稱＋秒數同一行，太長省略號）；原本兩行（名稱／秒數）在 32 高放不下。
  - 定位菱形（`kf-dot`）、特效圓圈（`fx-circle`／`tr-circle`）的位置跟著新的高度微調（菱形在片段底部內側、不超出軌道）。
  - `.track.tall` 樣式（給高的主軌用的）拿掉或改成跟一般軌一樣。
- 驗收：e2e——主軌片段高度 = 其他軌（取 `boundingBox().height`，差 ≤ 2px）；直式影片的縮圖格寬 ≤ 20px；長影片（90 秒）縮圖仍然鋪滿（I8 的測試照舊過）；片段名稱在一行內（`clip-label` 高度 ≤ 16px）。截圖 `docs/screenshots/ui-polish/`。
- 既有測試要注意：用座標點時間軸的（`deselect` 點第一軌最右邊 `y: 4`、`trim.spec` 拖把手、`track-drag.spec`、`i3.spec` 的版面）要確認還能點到；有寫死高度的斷言要改。
