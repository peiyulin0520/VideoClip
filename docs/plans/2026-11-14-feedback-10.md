## V1. 播放列按鈕與按下回饋（取代 U1）

- **按下去要看得出有按**（全站的按鈕都套）：

  - 有「開／關」狀態的（定位這個時間有定位、順暢／高清、安全區、全螢幕預覽…）：開著的時候底色＝主題色、字和圖示＝白色（`aria-pressed="true"` 統一套 `.on` 樣式）。
  - 底部工具列的 `ToolButton`、分頁、chip 都套同一個按下效果。
- **U2（影像軌變矮）照 `2026-11-14-ui-polish.md`**：`BASE_H` 44→32、縮圖最窄 18px、片段名稱一行。

## V3. 音訊「進階」：標記保留或標記靜音
- 音訊分頁每一列的「靜音標記」按鈕改名「**進階**」（`data-testid` 照舊 `audio-mute`，測試不用改按鈕）。
- 進去的面板（`MuteSheet` → 改名 `AudioRangeSheet`，標題「進階：聲音範圍」）上面多一個二選一：「**標記要保留的聲音**」／「**標記要靜音的聲音**」。
  - 保留模式：跟現在一樣，標起來的範圍有聲音、其他靜音（原色＝保留、灰＝靜音）。
  - 靜音模式：標起來的範圍**靜音**、其他保留（標記的範圍畫成灰色斜線、沒標的原色）。
  - 存的資料不變，一律是 `audioRanges`（保留的範圍）：靜音模式套用時，用「物件用到的整段素材範圍 − 標記的範圍」算出保留的範圍（純函式 `invertRanges(ranges, [from, to])`，放 `engine/audioRanges.ts`，單元測試）。
  - 打開時預設用上次的模式（存在這台手機 `vc-audio-range-mode`）；切換模式時，把目前的標記換成另一種表示（保留 ⇄ 靜音互換），畫面上同一段聲音的結果不變。
- 驗收：單元 `invertRanges`（中間挖一段、頭尾、整段、空）；e2e——靜音模式在 1–2 秒標一段 → `audioRanges` 是 [[0,1],[2,4]]、匯出的 1–2 秒靜音（沿用 `i4.spec.ts` 的匯出檢查）；切換模式後標記變成互補、套用結果一樣。

## V4. 版型：外框自由顏色＋透明度；版型附文字
### 外框顏色、透明度
- 版型面板（`LayoutPicker` 的選版型面板、以及版型分頁的「整個版型」面板）：外框顏色改用全站共用的 `ColorPicker`（32 色＋最近用過＋自訂，跟字卡一樣），四個舊選項保留成「常用」；加「外框透明度」滑桿（10%～100%）。
- 做法：外框是一張 PNG（`renderFramePng(def, W, H, color)`）。透明度直接畫進 PNG（`globalAlpha`）——這樣格子裡的影片不會跟著變透明。改顏色／透明度＝重畫外框 PNG、換掉外框物件的素材（新素材、舊的留著給復原用），一步復原。
- `VideoItem` 外框多存 `frameStyle?: { color: string; opacity: number }`（之後重畫用；舊專案沒有就當白色 100%）。

### 版型附文字（跟著版型移動）
- 版型目錄（`engine/layouts.ts` 的 `LAYOUTS`）每個版型可以有 `texts?: { x, y, w, text, fontId, size, color, align }[]`（位置是「版型自己座標」的比例）。預設：
  - 拍貼機直條／拍貼機 2×2：底部白邊上「PHOTO BOOTH」＋下一行日期（今天，`YYYY.MM.DD`），手寫感字體。
  - 膠卷：上下齒孔旁小字「FILM 400」「▶ 12A」等底片號碼（等寬、字小）。
  - 拍立得：下方白邊一行「memories」＋日期。
  - 其他版型（分割、九宮格）不附文字。
- 建立版型時（`addLayout`）同時建立這些字卡：`TextItem`，放在字卡軌，`group` 跟版型相同、長度跟版型一樣；版型面板加一個開關「附上版型文字」（預設開）。
- **跟著版型一起動**：
  - `setTransform` 的「整組」邏輯（現在只處理影片／照片）把同 group 的字卡也算進去（字卡跟著整組 `transformAbout`）。
  - 定位（I7）：外框有定位時，`timeResolved` 讓同 group 的字卡也用外框的相對變化（跟格子一樣）。
  - 版型進出場特效（I5）：同 group 的字卡也套外框的特效（`applyGroupOrItemEffect`）。
  - 搬時間、改長度（`moveGroupTo`、`setGroupDuration`）、刪除版型（`removeGroup`）都要包含字卡（`TextItem.group` 已經有這個欄位，`removeGroup` 已經會刪同 group 的所有物件；確認 `moveGroupTo`／`setGroupDuration`）。
- **改內容、字體**：點預覽上的版型文字（或時間軸上的字卡）會選到那個字卡、切到「文字」分頁，跟一般字卡一樣改內容、字體、顏色、大小；**拖移它＝拖整個版型**（跟格子一樣）。文字分頁上方顯示「這是版型的文字，位置跟著版型」。
- 驗收：e2e——外框自訂顏色 #3366ff、透明度 50% → 預覽取樣外框的地方是半透明的藍（看得到底下）；格子裡的影片不透明；一步復原回原本的顏色。拍貼機版型建立後有「PHOTO BOOTH」字卡（`group` 相同）；拖整個版型 → 字卡位置跟著移動同樣的量；改字卡內容／字體 → 預覽字變了、位置不變；刪除版型 → 字卡也不見。
