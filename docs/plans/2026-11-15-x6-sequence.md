# X6 版型：一格多素材＋同步／依序（2026-11-15 改寫第二版，Opus 規劃，Sonnet 實作）

取代 `docs/plans/2026-11-14-feedback-12.md` 的「X6」一節，也取代本檔第一版（「輪流播放模式＋停格推算」）。

## 使用者原話（2026-11-15）
> 如果是輪流播，然後在播放軸中，各影像又無法區分對應格子，可能會有問題，因為我可能在各格子中放不同對應的影像，或是穿插色塊，若穿插色塊，該怎麼知道我是穿插在哪一個格子中？也就是在版型中，應該同一格可以有多個素材，或許是靠點選後，一個格子可以被多個素材選擇要在該格子

用詞（使用者定案，要像網頁介面、簡潔）：播放方式 **［同步］［依序］**；空檔 **［停格］［色塊］［透明］**；把素材換格子 **［移至格子］**。不要加說明小字。

## 現況（v2 架構）
- 版型＝外框物件（`isFrameItem`）＋每格一條格子軌（`groupRole:'cell'`，`track.cell` 是位置）＋成員軌（文字、貼圖、音效）。
- **一格只有一個素材**：`importIntoCell` 換掉舊的；`cellMain(track)` 取第一個；`CellSheet`（這一格視窗）、`applyCell`、`planCell`（素材比這一格短／長）都假設一格一個。
- 格子素材播完後，那一格顯示 `track.fill` 色塊（`scene.ts` 的 cell fill），沒設 fill 就是空的。
- 播放軸展開版型 → 「影像」子分類每格一列（`Timeline.tsx` 的 `sheads`／`rows[].sub`），**列上沒有標第幾格**。
- 影片時間 `sourceTimeClamped`（timeline.ts）；預覽 `player.ts` `syncVideo` → `videoSyncPlan`（已有停在第一格／最後一格的 hold）；單格輸出 `exportFrame.ts`、匯出 `exporter.ts`。

## 規則（做成什麼樣）
1. **一格＝一條小軌道，可以放多個素材**：影片、照片、**色塊**，在這一格裡照時間先後播；同一格的素材不重疊（跟一般軌道一樣）；時間夾在版型範圍內（`clampToGroup` 那套）。
2. **色塊是一段素材**：每段可以不同顏色、可以剪長短、可以拖、可以加文字。做法：色塊＝`type:'image'` 的格子素材，素材是一張產生出來的純色小圖（`Asset.origin:'color'`、`Asset.color`），所以畫面、匯出、裁切、轉場全部走照片那一套，不用新的物件種類。素材分頁、我的素材庫**不列出** `origin:'color'`。
3. **色塊上的文字**：文字物件記 `TextItem.onItem = 色塊素材 id`，位置在那一格中間、時間跟色塊一樣；色塊移動、改長度、刪除時文字跟著（取代舊的 `cellFor` 空白畫面文字；舊資料 `cellFor` 照舊能畫、載入時不轉）。
4. **空檔**（一格在某個時間沒有素材在播）：版型設定 `frame.gapMode`：
   - **停格**：顯示這一格「前一個素材的最後一格」；前面沒有素材 → 顯示「後一個素材的第一格」。停格沒有聲音。
   - **色塊**：顯示這一格的 `track.fill`（在這一格視窗選顏色；沒選用外框顏色）。
   - **透明**：什麼都不畫（露出底下）。
   - 新的版型預設**停格**；舊版型（沒有 `gapMode`）照舊（有 `fill` 畫色塊、沒有就透明）。
5. **同步／依序**是「幫你排好」的動作，排完一樣可以在播放軸自由拖：
   - **同步**：每一格的素材都從版型開頭開始（一格裡多個素材就一個接一個）。版型長度＝最長那一格。
   - **依序**：第 1 格的素材排最前面，第 2 格接在第 1 格最後一個素材後面……版型長度＝全部加起來。
   - 外框記 `frame.layoutPlay: 'sync' | 'seq'`（最後選的；介面亮哪一顆）。**依序時**：在某一格「加素材」或「拉長／縮短某個素材的尾端」，**後面各格的素材一起往後／往前推**（漣漪）；在播放軸自己拖素材本體不推別人。同步時不推。
6. **看得出是哪一格**：
   - 播放軸每一格那列的軌道圖示改成**格子編號**（「1」「2」…，有命名就顯示名稱的前 2 個字），編號跟示意圖、預覽上的「第 N 格」一致。
   - 選到某一格的素材（或點那列的圖示）→ 預覽上**框出那一格**（虛線框＋「第 N 格」小標，用現有 `.clip-area`／`.clip-tag` 的樣式）。
7. **把素材放進某一格**：
   - 播放軸那一格的列**尾端 ＋** → 選單：［影片／照片］［色塊］，加在那一格最後一個素材後面（版型範圍不夠就把版型拉長）。
   - 選到版型裡的某個格子素材 → 剪輯分頁有［移至格子］→ 小選單列出 1～N 格 → 搬過去（時間不變；那一格那個時間有東西就找最近的空位；畫面照新格子的大小重新填滿裁切）。
   - 長按拖到同一個版型的別格那一列（F5 的拖移，限同一版型的格子列）。
   - 空格子的 ＋ 匯入（`EmptyCellSlot`）照舊。

## 步驟

### X6-1 資料與引擎（純函式＋單元測試）
- `model/types.ts`：`Asset.origin` 加 `'color'`、`Asset.color?: string`；`VideoItem.layoutPlay?: 'sync' | 'seq'`、`VideoItem.gapMode?: 'hold' | 'fill' | 'none'`（外框用）；`TextItem.onItem?: string`。
- 新檔 `src/engine/cellGap.ts`：
  - `cellAt(track, t): { item, held: 'before' | 'after' | null } | null`：這一格這一刻要畫的素材——有素材在播就是它；空檔時照 `gapMode`：停格回傳前一個（`after`）或後一個（`before`）素材、色塊／透明回傳 null。只在版型範圍（含版型轉場的提前／延長）內。
  - `playTime(item, t, held)`：held 時把 t 夾進那個素材自己的範圍（after → `start+duration−1/30`；before → `start`）。
  - 測試 `cellGap.test.ts`：一格兩段影片中間空 1 秒 → 空檔停在第一段最後一格；第一段之前 → 第二段……的第一格（before）；`fill`／`none` 回 null；舊版型（沒有 gapMode）行為不變。
- `layersAt`（timeline.ts）：格子軌改用 `cellAt`（取代「找 t 落在 [start,end) 的物件」）。
- 影片時間：`player.ts` `syncVideo`、`exportFrame.ts`、`exporter.ts` 在 `sourceTimeClamped` 前用 `playTime` 夾 t；`videoSyncPlan` 加 `held` 參數 → 直接停住（差超過 0.05 秒才 seek），不 play。停格時音量 0（`syncVideo` 的 vol 乘 0；混音 `audio.ts` 照素材自己的 start/duration 算，本來就不含空檔）。
- scene 的 cell fill（`scene.ts`）：條件改成「`cellAt` 回 null 且 gapMode 是色塊（或舊版型有 fill）」。
- 色塊素材：`src/engine/colorAsset.ts` `makeColorAsset(color): Promise<{ asset, blob }>`（16×16 純色 PNG，存法跟匯入照片一樣，`origin:'color'`）。同一個顏色重複用同一個素材（找 `assets` 裡 `origin==='color' && color===c`）。

### X6-2 動作（store，一步復原）
`src/store/actions.ts`：
- `addToCell(trackId, asset | { color })`：加在那一格最後一個素材後面（照片、色塊預設 2 秒；影片＝素材長度，最多 10 秒）；超出版型結尾 → 版型拉長（`setGroupDuration`）；依序時後面各格往後推。
- `moveToCell(itemId, cellTrackId)`：［移至格子］；重新算填滿裁切（`cellItem`／`cellTransform` 用新格子的 rect）；帶著 `onItem` 的文字一起搬（文字位置換到新格子中間）。
- `arrangeGroup(group, 'sync' | 'seq')`：同步／依序（規則 5），設 `layoutPlay`、改版型長度。
- 漣漪：依序時，改尾端（`trimEndFree` 走的那條路，格子素材）與 `addToCell` 之後，順序在後面的格子的所有素材 `start += delta`，版型長度跟著。寫成 `rippleAfterCell(d, group, cellIndex, delta)`。
- `setGapMode(group, mode)`。
- 既有要改：
  - `importIntoCell`：空格放第一個素材照舊；**不再換掉**舊素材——非空的格子改呼叫 `addToCell`（「換素材」改在這一格視窗裡對選到的那一段做）。
  - `applyCell`：改成對「這一格視窗裡選到的那一段」操作（名稱是格子的名稱存在 track 上：`track.name` 或新欄位 `track.label`；片段範圍是那一段的入點、長度）。拿掉「素材比這一格短／長」（空檔規則取代），舊的 `planCell` 留給同步時第一次放素材用。
  - 刪除格子素材：帶著 `onItem` 文字一起刪；依序時後面的往前補（漣漪 −長度）。
  - `addLayout`：新版型 `gapMode:'hold'`、`layoutPlay:'sync'`。
- 測試 `src/store/cellMulti.test.ts`：一格加兩段＋一段色塊、順序與時間；移至格子（裁切換新格子、文字跟著）；同步／依序的 start 與版型長度；依序時拉長第 1 格某段 → 第 2、3 格往後推；同步時不推；刪除一段依序往前補；一步復原。

### X6-3 介面
- **版型分頁**（`tabs/LayoutTab.tsx`，GroupPanel，示意圖下面一個 `.zone-soft`）：
  - 「播放方式」［同步］［依序］（radio，aria-label `播放方式 同步`／`播放方式 依序`）。
  - 「空檔」［停格］［色塊］［透明］（radio）。
  - 立刻生效、可復原（跟外框顏色一樣，不是彈出視窗）。不加說明小字。
  - 示意圖每一格左上角顯示編號（`LayoutDiagram` 加 badge，跟播放軸一致）。
- **播放軸**（`Timeline.tsx`）：
  - 格子列的軌道圖示顯示**編號**（`.cell-no`，有名稱顯示前 2 字），aria-label `第 N 格`。
  - 列尾 ＋（每一格都有，不只空格）→ 選單［影片／照片］［色塊］（色塊選顏色用現有 `ColorPicker` 的 32 色＋最近用過）。
  - 色塊片段畫成那個顏色、名稱「色塊」。
  - 長按拖素材：允許拖到同一版型的其他格子列；拖到版型外的列 → 不行（toast「版型裡的素材只能移到同一個版型的格子」）。
- **預覽**（`Preview.tsx`）：選到格子素材或點格子列圖示 → 那一格的範圍畫虛線框＋「第 N 格」（重用 `.clip-area`／`.clip-tag`；版型有旋轉時用多邊形）。
- **剪輯分頁**（選到格子素材時）：工具列加［移至格子］→ 小選單（1～N 格，目前這格反白）。用 `.btn-zone` 跟一般剪輯工具分開（使用者規則：不同層級要分區）。
- **這一格視窗**（`CellSheet.tsx`）：上面「名稱」；中間這一格的素材清單（縮圖小方塊，依時間；色塊顯示顏色）＋［＋影片／照片］［＋色塊］；點清單裡一段 → 下面顯示那一段的「片段」範圍（起迄可拖）、色塊顯示顏色選擇、可［刪除這一段］；「空檔顏色」（這一格的 fill）。照舊有「套用／儲存」。

## 驗收
- 單元：X6-1、X6-2 列的全部。
- e2e 新檔 `e2e/x6-cells.spec.ts`：
  1. 三格版型；第 1 格加紅（2 秒）、再按列尾 ＋ 加一段黃色色塊（2 秒）、再加綠（2 秒）→ 第 1 格三段依時間排好；播放軸第 1 格列圖示顯示「1」；第 3 秒時第 1 格中間是黃色。
  2. 空檔：把黃色色塊刪掉 → 第 3 秒（空檔）時第 1 格停在紅色最後一格（停格）；版型分頁切［色塊］→ 變成那一格的空檔顏色；切［透明］→ 露出底下影片顏色。
  3. 第 2、3 格各放藍、白；按［依序］→ 第 2 格的素材 start＝第 1 格最後一段結束、第 3 格接在後面；版型長度＝全部加總。按［同步］→ 每格第一段 start＝版型開頭。
  4. 依序時，播放軸把第 1 格最後一段尾端拉長 1 秒 → 第 2、3 格的素材都往後 1 秒；一步復原。
  5. 選到第 1 格的綠色 → 剪輯分頁［移至格子］→ 第 3 格 → 綠色在第 3 格那一列、畫面在第 3 格的位置；預覽框出第 3 格。
  6. 單格輸出：第 3 秒的各格中間顏色跟預覽一樣。
- 既有：`layout.spec`、`x5.spec`（這一格視窗會改，要跟著改）、`l0`、`l3`、`l5`、`g4` 通過。

## 風險與限制
- 這一格視窗改動最大（從「一個素材」變「素材清單」），`e2e/x5.spec.ts` 會有不少要改。
- iPhone 同時解碼數：同一格多段影片只會同時開一支（加上停格的那支）；超過 `MAX_CELL_VIDEOS` 照舊提醒。
- 停格第一次 seek 到最後一格，iPhone 可能閃一下（列進 iPhone 驗收）。
- 依序的漣漪只在特定動作發生；使用者自己拖素材本體不會推別格（刻意的，排完可以自由調）。
