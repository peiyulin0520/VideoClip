## F1. 主題：淺色基底、米色系、片段文字對比（使用者 1、4）

### 現況
- 主題在 `src/app/styles.css`：`:root`（暗黑）、`:root[data-theme='mono'|'fresh'|'warm']` 覆蓋變數。
- 清新（fresh）本來就是淺色（`--bg:#f4fbf9`），問題在時間軸：`.clip.is-text { background:#3b3350 }`、音樂片段 `#1f3b3a` 是**寫死的深色**，字的顏色卻跟著主題的 `--fg`（清新是深綠）→ 深底深字。
- 溫暖（warm）是深咖底（`--bg:#2a1f18`）。

### 做法
1. **溫暖改成圖三的米色系**（淺色基底），建議值（Sonnet 可微調，但要過 §F1 驗收的對比測試）：
   ```
   color-scheme: light;
   --bg:#f6f0e6;   /* 米白 */
   --panel:#fffaf2;
   --fg:#3b2a20;   /* 深咖啡字 */
   --muted:#8a7464;
   --accent:#b8553a; /* 磚紅（赤陶） */
   --on-accent:#fff8f0;
   --line:#e8dccb;
   --btn:#efe5d6; --btn2:#e6d8c4;
   --field:#fffaf2; --border:#d6c4ad;
   --clip:#e2d3bd; --bar:#b9a184; --timeline:#f1e8da;
   ```
   - 標題（頂列專案名、面板標題 `h2/h3`、分頁文字）在溫暖主題改襯線字：`--font-head: 'Noto Serif TC','Songti TC','PMingLiU',serif;`（iPhone 內建 Songti TC，**不另外下載字體**）。其他主題 `--font-head` = 原本的字體。
   - 名稱維持「溫暖」，設定頁說明改成「米色底、磚紅重點」。
2. **清新**保持淺色，只調：`--clip` 稍深一點讓片段跟時間軸底分得開（例如 `#bfe0d9`）、`--accent` 改 `#0f9f8f`（白字在上面才夠對比）。
3. **時間軸片段顏色全部改用主題變數**（不再寫死）：在 `:root` 與每個主題加
   ```
   --clip-media / --clip-media-ink     影片、照片、貼圖
   --clip-text  / --clip-text-ink      字卡
   --clip-audio / --clip-audio-ink     音樂、音效
   --clip-effect/ --clip-effect-ink    特效（F4 之後才有，先定義）
   --clip-gap-ink                      空白虛線框的字
   ```
   - 規則：**深色片段配淺色字、淺色片段配深色字**；字卡片段在淺色主題建議用「中深色＋白字」（例：清新 `#5b7f9a` / `#fff`，溫暖 `#8a5a44` / `#fff8f0`，黑白 `#333` / `#fff`），音樂片段同理（清新 `#3f8f86`/`#fff`、溫暖 `#6f7f5a`/`#fff`）。
   - `.clip-label`、片段上的時間、♪ 圖示、字卡片段裡的字都用對應的 `-ink`；縮圖上的標籤加 `text-shadow: 0 1px 2px rgba(0,0,0,.6)` 並用白字（縮圖底色不固定，像圖四一樣白字＋陰影）。
   - 找出所有寫死顏色：`grep -n "#[0-9a-fA-F]\{3,6\}\|rgba\?(" src/app/styles.css`，時間軸、按鈕、面板、彈窗裡寫死的深色底或深色字都換成變數（預覽畫面本身維持黑底不變）。
4. 主題的狀態列顏色（`src/ui/theme.ts` 的 `THEMES[].bar`）跟著新的 `--bg` 更新；`index.html` 早期 inline script 的對照表也要改。

### 驗收
- **單元測試（新）`src/ui/themeContrast.test.ts`**：讀 `styles.css` 文字，解析每個主題的變數（沒有覆蓋的取 `:root`），用 `src/engine/colorMath`（已有）的相對亮度算 WCAG 對比：
  - `--fg` 對 `--bg`、`--fg` 對 `--panel` ≥ 4.5
  - `--on-accent` 對 `--accent` ≥ 4.5（按鈕字）
  - 每一組 `--clip-*` 對 `--clip-*-ink` ≥ 4.5
  - `--muted` 對 `--panel` ≥ 3
  - 溫暖、清新、黑白的 `--bg` 相對亮度 > 0.7（淺色基底）
- **e2e `e2e/theme.spec.ts` 修改**：原本「溫暖是深色」的期望改成淺色；新增：清新／溫暖下加一張字卡＋一段音樂，量時間軸字卡片段的 `.clip-label` 計算後顏色與片段底色，對比 ≥ 4.5（用 `getComputedStyle`）。
- 截圖 `docs/screenshots/feedback-6/theme/`：四個主題的編輯器（有影片、字卡、音樂）＋設定頁。
- 🔴 iPhone：看溫暖的米色、襯線標題是不是像圖三；看時間軸字卡的字看得清楚。

## F2. 預覽直接點影片選取、縮放（使用者 2）

### 現況
- `src/app/editor/Preview.tsx`（約 147 行）`hitIds` 把主軌與鎖住的軌道排除 → 主軌影片只能從時間軸選；選了之後才能雙指縮放。
- 這是 2026-11-11 Fix-B 的決定（「點預覽不選主軌」，因為使用者當時嫌主軌一選就出現框）。**這次使用者明確要可以點**，以新的要求為準（記進 PROGRESS 修正紀錄）。

### 做法
1. `hitIds`：拿掉 `kind !== 'main'` 的排除（F4 之後也沒有 main 了），只排除鎖住、隱藏的軌道。點擊命中由上往下第一個（已有 `hitTest`）。
2. **防誤觸**（使用者擔心往上滑時點錯）：
   - 預覽上「點」只在 pointerup 時判定：移動 < 8 px、時間 < 350 ms 才算點；超過算捲動，不改選取。
   - 點到**沒有東西的地方不取消選取**（目前若會取消就改掉）；取消選取改成「再點一次同一個已選物件」以外的方式：點時間軸空白、或按選取框以外的「完成」— 建議：點預覽空白＝不動作，點時間軸空白＝取消選取。
   - 已經選了一個物件時，雙指手勢**不管手指落在哪裡**都作用在已選物件（不用剛好按在物件上）。這樣選好後整頁捲上去，直接在預覽任何位置雙指縮放。
3. **疊在一起時怎麼選到下面那個**：
   - 同一點再點一次（移動 < 8 px、間隔 < 600 ms 內第二次點擊不算；>600 ms 的再次點擊）→ 輪到這一點下面的下一層（cycle）。
   - 預覽右上角加小按鈕「查看圖層」（圖四有）：打開一個小清單，列出播放頭這一秒在畫面上的所有物件（由上到下，縮圖＋名稱＋軌道名），點一個就選它並捲到時間軸上那個片段。鎖住的顯示 🔒 不可選。
4. 主軌影片被選了以後，選取框、雙指縮放旋轉、拖移都跟疊加物件一樣（`setTransform`）。主軌影片原本的 `fit`（填滿／完整）在使用者手動縮放後改成 `transform`（已有的機制，確認主軌也走同一套）。
5. 「放大預覽」（圖四有）**這次不做**，記在之後的想法；目前預覽已經是滿寬。

### 動到的檔
`src/app/editor/Preview.tsx`、`src/app/editor/TransformControls.tsx`（雙指不必按在物件上）、新 `src/app/editor/LayerPeek.tsx`（查看圖層清單）、`src/engine/geometry.ts`（`hitTestAll(p,t,x,y)` 回傳該點所有命中，由上到下）。

### 驗收
- 單元：`hitTestAll` 疊三層時回傳順序正確、鎖住／隱藏不在裡面。
- e2e（新）`e2e/preview-select.spec.ts`：
  - 只有主軌一支影片，點預覽中央 → 選到它（時間軸該片段有選取樣式）、出現選取框；雙指縮小（CDP touch）→ `transform.scale` 變小。
  - 主軌＋一個疊加照片疊在同一點：第一次點選到照片，過 700 ms 再點同一點選到主軌影片。
  - 在預覽上拖一段 40 px 的捲動手勢 → 選取不變。
  - 「查看圖層」列出 2 個，點主軌那個 → 選到主軌。
  - 點預覽空白（影片縮小後露出的黑邊）→ 選取不變。
- 既有要改的測試：`e2e/` 裡斷言「點預覽不會選到主軌」的（Fix-B 時加的，`grep -rn "主軌" e2e/` 找；名稱可能在 `safe-zone`／`phase2` 相關 spec）改成新行為。
- 🔴 iPhone：選好後往上捲、在預覽任何地方雙指縮放；疊兩層時點兩次能選到下面那層。

## F4. 影像軌統一、軌道依種類分區（使用者 5，資料面）

### 決定
1. **主軌與疊加軌合併成同一種「影像軌」**（`kind:'media'`）：放影片、照片、貼圖、GIPHY、之後的畫畫。每一軌地位一樣：都可以上下換順序、都可以放在任何時間、都可以拖到別的影像軌。
2. **軌道種類**：`'media' | 'text' | 'effect' | 'audio'`。
   - `text`：字卡。
   - `effect`：特效（K6 調節層、之後的濾鏡／底片效果），**這次只定義型別與分區，不做功能**。
   - `audio`：音樂、之後的音效。
   - 素材只能放進同種類的軌道（影像不能進字卡軌，依此類推）。
3. **分區（不混合穿插）**：圖層由下到上固定是 **影像區 → 特效區 → 字卡區**；音訊區不參與畫面，在時間軸畫在最下面。每一區裡面的軌道可以自由換順序，**不能跨區**。
   - 時間軸由上到下顯示：字卡區、特效區、影像區、（分隔線）音訊區。
   - 這樣「字卡永遠在影像上面」。如果之後使用者要字卡在某張照片下面，再談（記在之後的想法）。
4. **磁吸（主軌那種一段接一段、刪掉會補齊）**：使用者要求「每一層都可任意拖拉」，所以**全部軌道都改成自由擺放**，靠吸附讓片段頭尾對齊：
   - 拖移、修剪時吸附到：同軌與上下軌片段的頭尾、播放頭、0 秒（已有 snap 邏輯，套到所有軌）。
   - 匯入影片：放在最下面那條影像軌的最後一段後面（等於以前主軌的行為）。
   - 刪除：預設只刪這一段、留空位；剪輯分頁的刪除鈕旁邊加「刪除並補齊」（後面同軌的片段往前移，填掉空位）。

## F5. 時間軸長按拖移素材（使用者 5，操作面）

### 手勢
- **短按**：選取（不變）。**手指在時間軸上滑**：捲動時間軸（不變）。
- **長按 400 ms**（手指移動 < 8 px）：片段「拿起來」——震動（`navigator.vibrate?.(10)`，iPhone 不支援就沒有）、片段放大 1.04 倍加陰影，跟著手指移動：
  - 左右移動＝改時間（吸附：同軌與上下軌片段的頭尾、播放頭、0 秒；吸附時顯示 `.snap-line`）。
  - 上下移動＝換軌道：手指在哪一軌，那一軌高亮；**只有同種類的軌道會高亮**，其他種類的軌道變灰、放開會彈回原位並提示「影像只能放在影像軌」之類（依種類換字）。
  - 拖到同區最上面那軌的上方／最下面那軌的下方 → 出現一條「＋ 新增一軌」的放置線，放開就新增一軌放進去。
  - 放開時跟目標軌的片段重疊 → 自動找最近的空位（`findFreeStart`）；找不到（例如中間塞滿）就在旁邊新增一軌放進去，並提示。
  - 拖到時間軸可見範圍的左右邊緣或上下邊緣 → 時間軸自動捲動（每格 8 px）。
- 拖移中再放第二根手指＝取消，彈回原位。
- 一次拖移＝一步復原（`coalesce` 用 `drag:<id>:<pointerId>`，避免跟前一次拖移被合併；注意 HANDOFF §5「連續同 key 拖移會被合併」的坑）。
- 軌道整條換順序：保留左側軌道圖示拖拉（已有），但限制在同區內。

### 動到的檔
- `src/app/editor/Timeline.tsx`：抽出 `useLongPressDrag`（新 `src/app/editor/useClipDrag.ts`）；目前片段的拖移（自由軌左右移）併進來：**沒長按直接拖＝捲動時間軸**，長按後才拖片段（使用者這次的明確要求；以前自由軌是直接拖就移動，要改）。修剪把手維持直接拖（不用長按）。
- `src/store/actions.ts`：新 `moveItemTo(id, trackId | {newTrackAt: index}, start)`，一個 action 完成「從原軌移除、必要時新增軌道、放進目標軌」，原軌空了**不自動刪軌**（使用者可能還要放），圖層分頁可刪。
- `src/engine/timeline.ts`：`dropTarget(p, kind, y-row, start, duration)` 純函式算放到哪（可單元測試）。

### 驗收
- 單元：`dropTarget`（同種類、不同種類拒絕、重疊找空位、塞滿新增軌道、拖到區邊緣新增軌道）。
- e2e（新）`e2e/clip-drag.spec.ts`（CDP touch，長按用 `touchStart` 後等 500 ms 再 `touchMove`）：
  - 影像 1 的片段長按拖到影像 2、時間往右 2 秒 → 片段在影像 2、`start` 約 +2（吸附誤差 0.1 秒內）；影像 1 原位置變空位。
  - 影像片段拖到字卡軌 → 彈回原位、有提示。
  - 拖到影像區最上方 → 多一條影像軌。
  - 沒有長按直接滑 → 時間軸捲動、片段不動。
  - 復原一次 → 回到拖移前。
  - 長按中第二根手指 → 取消。
- 截圖：拖移中（目標軌高亮、新增一軌的放置線、不可放的軌變灰）。
- 🔴 iPhone：長按 400 ms 的手感、會不會跟 iOS 的長按選字／放大鏡衝突（時間軸要 `-webkit-user-select:none; -webkit-touch-callout:none`）、自動捲動速度。
