## 2. 要改的事

### ① 匯入失敗（P0，必做，先做）

1. **錯誤訊息分步驟**（`src/engine/importMedia.ts`）：分成「存到手機」「讀影片資訊」「產生縮圖」三段各自 try/catch，失敗訊息改成白話＋步驟＋檔案大小，例如：
   `無法匯入 IMG_8177.mov（312 MB）：存到手機時失敗（記憶體不足）`。原始英文訊息另外 `console.warn`，並記在 `window.__videoclip.lastImportErrors`（除錯用）。
2. **縮圖失敗絕對不能讓匯入失敗**：`probeMedia` 裡產生縮圖的部分整段包起來，任何錯誤 → `thumbs: []`（之後由播放器補縮圖，修正 C 已有）。
3. **Mediabunny 縮圖加保護**（`src/engine/probe.ts` `mediabunnyThumbs`）：
   - 影片解析度 > 1920（長邊）或檔案 > 150 MB 時**跳過 WebCodecs 解碼**，直接走 `<video>`／播放器補圖（4K HEVC 解碼很吃記憶體）。
   - `CanvasSink` 不要同時傳 `fit` 卻只給 `height`（Mediabunny 的 `fit` 只在寬高都給時才有意義）；改成給 `width` 和 `height` 兩個（依顯示比例算好）＋`fit:'contain'`，或只給 `height` 不給 `fit`。
   - 每張縮圖之間 `await` 一個 macrotask，讓頁面有機會回收。
4. **存檔改成分段寫入＋多層退路**（`src/storage/media.ts` `putMedia`）：
   - OPFS：改成 `for (offset…) await w.write(blob.slice(offset, offset + 8MB))`，不要一次寫整個 Blob。
   - OPFS 失敗（任何錯誤）→ 刪掉寫一半的檔案 → **退回 IndexedDB**（`db.put('blobs', blob, key)`；IndexedDB 存 Blob 在 Safari 是用檔案存的，不會整個進記憶體）。
   - IndexedDB 也失敗 → **最後退路：這次先只放在記憶體裡**（`assetUrls.ts` 已有 `URL.createObjectURL` 的流程，把 File 物件留在 Map 裡），素材照樣能剪輯；toast 提醒「這支影片太大，沒辦法存在手機裡，關掉網頁後要重新匯入」，素材標記 `unsaved: true`（型別加選填欄位），首頁/編輯器重開時找不到檔就顯示「素材遺失，請重新匯入」而不是壞掉。
   - 匯入前呼叫 `navigator.storage.estimate()`，剩餘空間 < 檔案大小 × 1.2 時直接提示空間不足（不要等到寫入一半才失敗）。
5. **進度**：大檔案寫入時 `setBusy('匯入中… 存檔 45%')`（依已寫入的位元組數）。
6. 測試（Chromium 模擬 iPhone 的失敗情況）：
   - e2e：`addInitScript` 把 `FileSystemWritableFileStream.prototype.write` 改成丟 `new DOMException('…', 'UnknownError')` → 匯入仍成功（走 IndexedDB），重新整理後素材還在。
   - e2e：OPFS 和 IndexedDB 都弄壞 → 匯入仍成功、出現「沒辦法存在手機裡」提示、可以播放。
   - e2e：`VideoDecoder` 的 `decode` 丟錯 → 匯入仍成功、之後補上縮圖。
   - 單元測試：分段寫入的 offset 計算、錯誤訊息格式。
   - 🔴 **iPhone 真機驗證**（列進 `docs/PLAN.md §7`）：用使用者這支 `IMG_8177.mov`（或任一支 1 分鐘以上的 4K 影片）匯入成功；重新整理後還在。**請使用者回報新的錯誤訊息全文**（會顯示是哪一步），若仍失敗再對症處理。

### ② 預覽太小＋選取操作鈕（必做）

**目標**：文字分頁打開時，9:16 預覽在 iPhone（390×664 可視區，扣掉 Safari 網址列）至少 **42% 螢幕高**（約 280pt 高、158pt 寬）；收合面板時 ≥ 60%。

1. **編輯時自動縮小時間軸**（`Editor.tsx`、`Timeline.tsx`、`styles.css`）：
   - 底部面板展開（任何分頁）時，時間軸變成**精簡模式**：高度 56px，只顯示目前選取物件所在的那一條軌道（沒有選取就顯示主軌），其他軌道收起；左側加一個「展開時間軸」小按鈕（≥44px）。
   - 面板收合時恢復完整時間軸。
   - 精簡模式下仍可左右滑動移動播放頭、點片段選取。
2. **底部面板改成「疊在時間軸上」的抽屜**，最高 32dvh；面板上緣有一條可拖動的把手（往下拖＝收合）。分頁列（剪輯/疊加/文字/圖層）固定在最下面。這樣預覽 = 螢幕 − 頂列 − 播放列 − 精簡時間軸 − 面板。
3. **預覽最小高度**：`.stage-wrap { min-height: 40dvh }`；空間不夠時優先壓縮面板（面板內可捲動），不壓縮預覽。
4. **全螢幕預覽鈕**：預覽右上角加「放大」圖示（≥44px），點了預覽佔滿螢幕（面板與時間軸隱藏），仍可拖移/縮放物件，再點一次回來。
5. **選取操作改成「直接在物件上縮放」**（使用者選項：「不要那個 icon，可以在點選的文字或圖塊直接縮放」）：
   - **拿掉 ✕ 刪除鈕**（刪除改到文字面板的分頁列多一個「刪除」、剪輯分頁原本就有刪除）。
   - **拿掉粉紅大縮放鈕**，改成選取框**四個角的小圓點**：看得到的點 10px（白色＋細陰影），觸控區 36px 並且**往框外偏**（不蓋住物件本身）；拖任何一角＝以中心等比縮放（`setTransform` 的 scale，coalesce 成一步復原）。
   - 旋轉：保留雙指旋轉；另外在選取框上方中間加一個小「旋轉點」（同樣 10px 可見、36px 觸控，離框 18px），拖它旋轉（吸附 0/90/180/270，沿用 `snapRotation`）。
   - **單指拖物件本身＝移動**（已有）；**雙指＝縮放＋旋轉**（已有）；物件很小時（< 44px）觸控範圍自動放大到 44px（`pointInBox` 判斷時把框外擴）。
   - 選取框線改 1.5px 白＋外圈 1px 黑（在亮/暗背景都看得到）。
6. **選取框＝看得到的內容，不是整張畫布**（修 2c）：
   - `renderText` 多回傳 `content: {x,y,w,h}`（字塊∪文字墨跡含描邊∪裝飾的實際範圍，相對畫布左上角；用曲線取樣而不是控制點算裝飾範圍）。
   - `measureTextItem` 回傳 content 的寬高＋相對畫布中心的偏移 `(dx,dy)`；`itemBox` 把偏移依旋轉角換算後加到 `cx/cy`。合成器照舊把整張畫布以中心對齊（畫面不變），只有選取框、點選範圍、吸附用 content。
   - 單元測試：有尾端圈圈的字卡，選取框寬 ≈ 文字寬 ×1.3，不是整張畫布。
7. **空專案匯入鈕**（修 2d）：移到 `.stage-wrap` 裡面置中（預覽中央），不再相對整個編輯器定位。
8. 測試：e2e 量 iPhone 13 尺寸下，文字分頁展開時 `stage` 高度 ≥ 0.42 × viewport 高；四角拖曳縮放、旋轉點、雙指仍可用；小物件仍點得到；全螢幕切換；截圖改前/改後對照。

### ③ 顏色更彈性（必做）

1. 新共用元件 `src/ui/ColorPicker.tsx`，**所有選顏色的地方都換成它**（文字、字塊、字塊外框、描邊兩層、裝飾、陰影）：
   - 第一排：**最近用過的 8 色**（每台裝置記在 localStorage `vc-recent-colors`，最新在前）。
   - 色票：擴充到 **32 色**，分 4 排：基本（白黑灰、正紅橘黃綠藍紫）、粉嫩（馬卡龍）、莫蘭迪（低飽和）、螢光（霓虹）。
   - 「**自訂**」按鈕：打開 `<input type="color">`（iOS 17+ Safari 會跳系統取色器，有色盤、滑桿、滴管）；旁邊顯示目前色碼，可直接輸入 `#RRGGBB`。
   - 色票圓點 36px、觸控區 ≥ 44px（列與列之間不留縫）。
2. 文字顏色另加「**透明度**」滑桿（存成 `rgba`／或 run 多一個 `opacity`）——可選，若時間不夠先不做。
3. 資料格式不變（仍是字串色碼），舊專案不用轉換。
4. 測試：e2e 點「自訂」→ 設定 `#12ab34` → 文字顏色變了、最近用過出現這個顏色、重新整理後最近用過還在；32 色每一格都點得動。

### ④ 裝飾：可以調「跟文字的距離」（必做）

1. `Decoration` 加選填欄位 **`gap?: number`**（佔字高的比例，預設 0＝現在的位置，範圍 −0.3 ~ 1.0）、**`scale?: number`**（裝飾大小，星星/愛心/勾勾/箭頭用，預設 1，範圍 0.5 ~ 2）。
2. `decorations.ts` 每種裝飾依類型套用 gap：
   - **底線類**（波浪、虛線、點點、雙底線、尾端圈圈）：整條往下移 `gap × h`；**而且線寬往下長**（線的上緣固定在 `b + h*基準 + gap*h`），變粗時不會往上碰到字（修使用者截圖的問題）。
   - **包圍類**（手繪圈住、角括號）：往外擴 `gap × h`。
   - **兩側類**（愛心、斜線、打勾、星星、彎箭頭）：往左右（或外側）推開 `gap × h`。
   - **螢光筆**：gap 改成「往下偏移」（負值＝往上蓋住字多一點）。
3. 面板（`TextPanel.tsx` 裝飾分頁每一列）：粗細下面加「**與文字距離**」滑桿；星星/愛心/勾勾/箭頭加「**大小**」滑桿。
4. 預設值微調：波浪底線基準從 `0.28h` 改成 `0.32h`（線寬一半另外往下算），讓 25% 粗細時也不碰字。
5. 單元測試：每種裝飾 gap=0.5 時範圍確實離墨跡更遠；底線類粗細從 5%→25%，線的上緣 y 不變。e2e：拖距離滑桿 → 資料與預覽像素改變。

### ⑤ 字塊：像 Office 一樣調圖形（光滑度、凹槽深度…）（必做）

1. `CardBox` 加 **`adj?: Record<string, number>`**（圖形調整值；沒有＝預設值，舊專案不用轉換）。
2. `ShapeDef` 加 `adjust: { key, label, min, max, step, def }[]`，各圖形提供的調整（面板依目前圖形顯示對應滑桿，**都可即時預覽**）：

   | 圖形 | 調整 |
   |---|---|
   | 雲朵、思考泡泡 | **凸起數量**（5–14）、**凹槽深度**（0–1，0＝幾乎是橢圓）、**凹槽圓滑**（0–1：凸起之間的接縫用圓弧接，不是尖角） |
   | 波浪印章 | 波浪數量（10–30）、波浪深度 |
   | 星形（4/5/6/8 角）、爆炸 | **內徑比＝凹槽深度**（0.2–0.9）、**角的圓滑**（0–1）、（爆炸）不規則程度 |
   | 所有多邊形（三角、菱形、五/六/八邊形、十字、剪角、標籤、橫幅、箭頭、V 形、步驟條、斜切） | **角的圓滑**（0–1：每個頂點換成圓弧，半徑＝相鄰邊較短那邊 × 0.5 × 值） |
   | 斜切色塊 | 斜度 |
   | 方/圓角/橢圓對話框 | **尾巴位置**（沿底邊 0–1）、**尾巴長度**、**尾巴寬度**（現有左下/右下保留為快捷） |
   | 粗箭頭、V 形、步驟條、標籤、橫幅 | 箭頭/缺口大小 |
   | 圓角矩形 | 圓角（已有，搬到同一區） |
3. 共用工具（`shapes.ts`）：
   - `roundPolygon(points, t)`：多邊形每個角用二次/三次貝茲圓弧取代（給「角的圓滑」用）。
   - `scallop(w,h,n,depth,smooth)` 重寫：凸起用圓弧、凸起之間的凹槽可用小圓弧接（smooth），depth=0 時退化成橢圓。
4. **文字放得進圖形的範圍要跟著調整值變**：把寫死的 `inset` 改成**執行時計算**——`fitInset(shapeId, adj, aspect)`：把路徑取樣成多邊形，二分搜尋最小的 k 使「文字區（外框÷k）四角與四邊中點」都在圖形內（沿用 `shapes.test.ts` 的 `flatten`/`inside`，搬到 `shapes.ts` 共用），結果依 `shape|adj|長寬比四捨五入到 0.05` 快取。原本的 `inset` 表留作沒有調整時的預設值與測試基準。
5. （之後，可選）預覽上直接拖黃色「調整點」，像 Office 一樣——**這次先做滑桿**，調整點等使用者確認滑桿好用再做。
6. 測試：單元測試——每個可調圖形在 min/中間/max 三個值：座標有限、文字區放得進去、`smooth=1` 時多邊形沒有尖角（相鄰取樣點夾角都 > 某值）、雲朵 depth=0 時接近橢圓。e2e：選雲朵 → 拖「凹槽深度」到 0 → 預覽像素改變、資料有 `adj`；截圖總覽 `docs/screenshots/fix-feedback-2/shapes-adjust.png`（同一圖形三種調整值並排）。
