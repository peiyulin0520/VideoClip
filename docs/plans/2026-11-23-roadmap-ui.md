# 總規劃 v2 ＋ 介面重整（2026-11-23，Opus 規劃，Sonnet 實作）

使用者用「grill-me」方式（一題一題、每題附建議答案）跟 Opus 討論完整個 App 的方向與介面，以下是全部定案。
**每一項開工前，先依這份寫該項的細部計畫（或在這份補小節），再交給 Sonnet。**

---

## 0. 定案的順序

1. **U 介面重整**（含全螢幕＋鎖定）——本文件 §1 是完整規格
2. **預覽變順**（Y10）：使用者截圖「合成」每格 25–28 ms、預覽 15–20 fps（多影片＋轉動的版型外框＋839×960 畫布）
3. **備份**：手機檔案＋Google 雲端（規格在 `docs/PLAN.md` Phase 6，照做）
4. **畫畫**（X8 ＋ §3 的新增）
5. **錄音旁白、畫面特效、綠幕去背**
6. **對齊音樂節拍、變速曲線、自動人物去背**
7. **雲朵字、字卡模板、字卡逐字動畫**（`docs/EFFECTS.md §1` 的 TextAnim 逐字進出場與循環）
8. **AI 剪輯**（最後做，使用者說是「額外的輔助」）——§5
- 以後再說：自動字幕、文字轉語音

已經 push 但還沒進 PR 的兩個修正（跑馬燈類也能「停在最後畫面」、播放時影片凍住／沒聲音的 AudioContext 修正）跟 U 第一批一起開 PR。

## 1. U 介面重整

### 1.1 版面骨架（整頁不捲動）
- 編輯器＝一個螢幕高（`100svh`），**不再整頁捲動**。由上到下：
  1. 頂列
  2. 預覽
  3. 播放列
  4. 時間軸（吃掉剩下的高度，裡面上下滑）
  5. 功能列（最下面，一排）＋ iPhone 底部安全區
- **最下面不留白**：各區高度加起來剛好等於螢幕，換機型（320–430 寬、矮機如 SE）都成立。
- **預覽高度依專案比例**（使用者選 A）：
  - 直式（版面寬 ÷ 高 < 1，例 9:16、3:4）：預覽區高度 ≈ 螢幕 54%（沿用現在 `stage-wrap` 的算法：`min(寬×16/9, 螢幕−頂列−播放列, 螢幕×0.54)`）。
  - 方形、橫式（1:1、4:3、16:9…）：預覽區＝滿寬，高度＝版面高度＋上下一點邊（版面外面的東西仍看得到一小圈，建議每邊 6%），**多出來的高度給時間軸**。
  - 預覽底的寬高比仍＝預覽區的寬高比（`setBaseAspect`，2026-11-21 的做法），版面在底裡面等比放到最大、外面蓋斜線。
  - 改比例 → 預覽區高度跟著變（使用者接受；這是 A 的代價），切換時先頂著上一格畫面不閃。
- 預覽大小**不因開面板而改變**（使用者明確說預覽縮小會影響檢視）。

### 1.2 功能列：三層（使用者選 A）
1. **第一層：類別**（一排、可左右滑；7 類）
   | 類別 | 內容（原本在哪） |
   |---|---|
   | 剪輯 | 分割、刪除、刪除並補齊、複製、變速、裁切、片段範圍、**定格**（從播放列移來）、命名、開場留白…（作用在選中的素材；原「剪輯」） |
   | 加入 | 疊加影片／照片、貼圖（含 GIPHY、我的貼圖）、**畫畫**（之後）（原「疊加」＋「素材」） |
   | 文字 | 新增文字、圖形、動態字卡、字卡動畫、文字內容與樣式（原「文字」＋「特效」裡的文字特效入口） |
   | 版型 | 原「版型」 |
   | 特效 | 轉場、進出場、整段、**畫面特效**（之後）（原「特效」） |
   | 色調 | 原「色調」＋ **看原色比較**（從播放列移來） |
   | 音訊 | 背景音樂、音量、淡入淡出、**錄音旁白**、**對齊節拍**（之後）（原「音訊」） |
   - 原「圖層」分頁**拿掉**；圖層順序只留預覽右上角「圖層」一個入口（`LayerPeek`）。時間軸的「圖層（n）」標題改名或改成收合用的小標，不要跟這個重複用詞。
2. **第二層：工具／效果列**：點類別 → 這一排換成那一類的工具或效果，**左右滑**挑；最左邊「←」回第一層。效果類（轉場、色調組合、動態字卡、貼圖…）直接是一排縮圖，**點了立刻套用**。
3. **第三層：細調小視窗**：要調的東西多（顏色、滑桿、文字內容、字體…）才從下面升起小視窗；照 X2b／X2c 的規則有「套用」和「✕」。關掉就能直接拖播放軸看效果。
- **點素材自動跳**（使用者選 A）：在時間軸或預覽上點選素材 → 功能列直接跳到那個素材的工具（文字→文字、影片→剪輯…）；取消選取回第一層。
- **不能有字被切一半**：左右滑的那一排用 scroll-snap，最右邊淡出提示還有；按鈕字級用現有的 CSS 變數，320／360／390／430 四種寬度都不換行、不截斷。
- **說明小字全部拿掉**（使用者規則）：空白狀態只放圖示＋一句短標題。

### 1.3 時間軸
- 高度＝播放列和功能列之間剩下的高度，裡面上下滑。
- 點某個功能類別 → 時間軸自動捲到那類軌道並展開，其他類收成一列（只顯示名稱與數量）（使用者選 A）。
- 「縮小／放大」按鈕拿掉，改兩指捏合縮放時間軸（保留現在的縮放上下限；沒有兩指的桌機用 ctrl＋滾輪）。

### 1.4 頂列、播放列、預覽上的按鈕（使用者選 A）
- **頂列**：返回、專案名稱（含日期）、比例、畫質、匯出。
- **播放列**：播放、時間、復原、重做。（定格→剪輯；色調比較→色調；縮小放大→兩指）
- **預覽右上角**：圖層、**鎖定**（新）、全螢幕。
- **安全區**：縮成右下角一個小圖示，不放文字。
- **「框內是影片輸出範圍」**：不再常駐，只在換比例後出現約 3 秒。

### 1.5 全螢幕
- 按全螢幕 → 預覽撐滿頂列以下、播放列以上；時間軸和功能列收起來；頂列、播放列留著。
- 全螢幕裡照樣能點選、拖移、縮放素材。
- 播放列在全螢幕時多一條**可拖的細進度條**（時間軸收起來時用它跳時間）。
- 全螢幕時整頁不捲動，預覽固定。
- 進出全螢幕預覽區大小會變（會重建預覽引擎）：先用 `holdSnap` 頂著上一格，不閃黑。

### 1.6 鎖定
- 一般大小和全螢幕都有，放預覽右上角「全螢幕」旁邊，用鎖頭圖示（不用表情符號）；鎖住時按鈕亮起（主題色）。
- 預設不鎖；鎖住後切換全螢幕、換分頁都維持；離開專案、重新整理回到不鎖（存在 `uiStore`，不存 localStorage）。
- 鎖住時保留原本的選取，第三層小視窗的滑桿照樣能調；預覽上的選取框改淡淡的虛線，拖不動、縮放不了。
- 鎖住時點到素材不會動，短暫出現「已鎖定，按右上角鎖頭解開」（toast，2 秒，同一次觸碰不重複）。

### 1.7 建議的實作批次（Sonnet）
- **U1 骨架**：編輯器改一個螢幕高、各區高度計算（依比例）、時間軸區內捲動、功能列固定最下面；拿掉整頁捲動相關的程式（`Toolbar` 的 `scrollTo`、`Editor` 的捲到最上、preview-first 的整頁捲動測試要改寫）。
- **U2 功能列三層**：第一層 7 類、第二層左右滑、第三層彈出視窗；把現在各 Tab 的內容搬進去（先搬、再精簡），點素材自動跳。
- **U3 按鈕重新分配**：頂列、播放列、預覽上；時間軸兩指縮放；比例標籤只出現幾秒；安全區小圖示。
- **U4 全螢幕＋鎖定**。
- **U5 自我檢查**：四種寬度、四種比例截圖；說明小字清掉；沒有字被切；e2e 全改綠。
- 每批照 AGENTS.md：check、e2e、截圖（真人照片不進 repo）、PROGRESS／PLAN §7／HANDOFF。
- ⚠ 這是大改：很多 e2e 用「捲到最上」「openTab」找分頁。U2 先在 `e2e/helpers.ts` 的 `openTab` 加對照（舊分頁名 → 新類別），避免一次改爛幾百個測試。

## 2. 預覽變順（Y10）——細部規劃見 `docs/plans/2026-11-24-feedback-15.md` 第 3 批（Z13）
- 已知：合成每格 25–28 ms（不是解碼的問題，解碼器 2–3/6）。
- 先量再改：在效能框把合成拆成「濾鏡（色調、模糊）／遮罩（版型裁切多邊形）／貼圖上傳」各花多少；候選：版型外框轉動時的多邊形遮罩改成快取、調色濾鏡在 neutral 時跳過、畫布 839×960 在「流暢」降一半。

## 3. 畫畫（X8 規劃＋這次新增）
X8（`docs/plans/2026-11-14-feedback-12.md` 的 X8 節）照做，再加：
- **深淺**：用畫的速度模擬（慢＝粗、深；快＝細、淡）；`PointerEvent.pressure` 真的有值（iPad＋Apple Pencil）時改用壓力。
- **蠟筆**：有顆粒感的筆刷（紙紋貼圖做遮罩）。
- **兩種畫法**：
  - 「跟著影片畫」：影片播放時跟著畫，每一筆記錄「影片時間」；可以把影片放慢（0.25／0.5／1 倍）方便跟上；正常速度播放時畫的過程變回原速。
  - 「暫停畫」：停在某一秒畫，整幅畫一直不動（X8 原本的做法）。
- **每一筆留多久**（每幅畫選）：一直留著（到片段結束）／幾秒後淡出（秒數可調）。
- **背景淡化**：畫的時候一條「背景淡化」滑桿 0–90%，可切換蓋白或黑；只在畫的時候有，匯出沒有。

## 4. 錄音旁白、畫面特效、綠幕、節拍、變速曲線、人物去背——各自開工前細部規劃
- 錄音旁白：`MediaRecorder` 錄麥克風成音訊素材放在音訊軌（邊播影片邊錄、錄的時候影片聲音可關）。
- 畫面特效：`docs/EFFECTS.md §4`（顆粒、暗角、VHS、閃白、手震、光暈…），特效軌任意時間範圍。
- 綠幕去背：色鍵著色器（選顏色＋容差＋邊緣柔化）。
- 對齊節拍：分析背景音樂的節拍點，時間軸顯示節拍點、剪點與轉場可吸附。
- 變速曲線：片段裡速度隨時間變（預設幾種曲線＋自訂點）；聲音處理要另外討論。
- 自動人物去背：手機上跑的分割模型（不送雲端），先試 iPhone 上的速度與發熱。

## 5. AI 剪輯（最後做）
- **使用者要求**：不用 API 金鑰（金鑰跟訂閱分開算），要用自己的 **Claude 帳號**；不考慮其他 AI；不能讓開發者花錢。
- **事實**：別的網頁無法借用 Claude 訂閱；唯一可行的是**在 Claude 裡發佈的小程式**（Artifact 的 `sample` 能力，用打開的人自己的 Claude 帳號；額度歸屬實作前要再確認），託管在 claude.ai，不用伺服器、開發者不花錢。
- **方向**：同一套程式做兩個版本——GitHub 版（不用 AI）與 Claude 版（多「讓 AI 看素材、問問題、挑精華自動剪」）；兩邊互不相干，Claude 版除了 AI 問答，其餘介面跟 GitHub 版一樣。
- **開工前先做試驗版**驗證 4 點，任一點不行就退回「Claude 版只產生剪輯計畫檔、回 GitHub 版匯入」：
  1. 專案（IndexedDB／OPFS）在 Claude 裡會不會被清掉
  2. 在 Claude 頁面裡選手機大影片能不能讀取、播放
  3. 匯出 MP4 透過 `downloads` 能不能存到手機（大檔）
  4. iPhone 的 Claude App 裡能不能用這些功能
- 限制要跟使用者講清楚：Claude 只看畫面、聽不到聲音；用的是使用者自己的方案額度。
- 原本 Phase 7「推薦 IG 音樂」（設定頁填金鑰）**改到 Claude 版**做，不用金鑰。

## 6. 這次討論的原話重點（給接手的人）
- 「預覽縮小可能會影響檢視，應該是要調整功能列，讓他儘量精簡，然後可以變成是往左右滑挑選特效，而不是上下滑介面，然後有一些可以用成升起的 popup 視窗，選擇後關閉可以直接在播放軸拖拉看預覽畫面的效果」
- 「介面一開始的要最下面是功能列，往上是播放列、預覽畫面等，不要有最下面留白處，要因應機型、選擇的版型自我調整」
- 「主要是要 user friendly，不會看到一堆按鈕或是調整的東西不知道怎麼用，各功能也要明確分隔，在功能列或是預覽畫面中，文字不要卡到」
- 「AI 剪輯可以排最後，對我來說是額外的輔助功能」
