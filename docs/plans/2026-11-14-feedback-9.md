## I0. 新版一定會更新到手機（0）
現況：`src/app/pwa.ts` 用 `registerType: 'autoUpdate'`，開網頁、回到前景、每 30 分鐘檢查；但 iPhone 加到主畫面的 PWA 常常一直停在舊版。
1. 建置時多產生 `dist/version.json`（`{ "version": "<built>（<sha>）" }`，vite 外掛在 `generateBundle` 寫出），**不進 precache**，讀的時候 `fetch('version.json', { cache: 'no-store' })`。
2. 開網頁、回到前景時讀 `version.json`：跟 `APP_VERSION` 不一樣 → 先 `registration.update()`，等新的 SW 接手（`controllerchange`）後重新整理；10 秒內沒接手 → 顯示底部橫幅「有新版本（版本號）— 點一下更新」，點了＝ `skipWaiting` 訊息＋重新整理；還不行就清掉 `caches` 裡我們自己的快取再重新整理（專案資料在 IndexedDB／OPFS，不受影響）。
3. 設定頁最上面顯示「目前版本」＋「檢查更新」按鈕（同上流程，沒新版就提示「已經是最新版」）。
4. 編輯器頂列專案名稱下面用很小的字顯示版本日期（例如 `11/13 23:24`），使用者截圖時看得出版本。
- 驗收：e2e 用 `page.route('**/version.json')` 回一個不同版本 → 出現更新橫幅；設定頁「檢查更新」在版本相同時顯示「已經是最新版」。

## I1. 小修（6、4）
- **6 圖層分頁**：`LayersTab` 在畫面重畫時讀一次 `player?.time`，沒有訂閱播放時間，所以播放頭移動後清單還是舊的時間（使用者截圖剛好停在 0 秒前面的空白）。改成 `useState` ＋ `player.subscribe`（暫停時才更新清單；播放中每 0.5 秒更新一次就好，免得一直重畫）。e2e：播放頭從空白移到有素材的時間，清單出現那些圖層。
- **4 膠囊框線被擋**：橫向可滑的膠囊列（`.cat-chips`，貼圖、轉場分類都是）`overflow-x: auto` 會把上下的框線和 `box-shadow` 切掉。改成上下各留 4px（`padding: 4px 2px 8px`）、`scroll-padding`；所有 `overflow-x: auto` 的膠囊列一起檢查（音訊分頁、GIPHY、轉場卡片列）。截圖驗收。

## I2. 往回拖畫面消失；預設順暢；頂列切換（8）
**原因（推測，Sonnet 先用 e2e 重現）**：拖時間軸時每一格都 `el.currentTime = s`；iPhone 上往回 seek（尤其 HEVC，要從前一個關鍵畫格解碼）很慢，**前一個 seek 還沒完成就又設新的時間**，結果一直在 seeking、`ready` 一直是 false，畫面就只剩選取框（白框）。
1. **seek 排隊**（`Player.syncVideo`）：元素 `seeking` 中就不要再設 `currentTime`，記下「最新想要的時間」，等 `seeked` 事件再設一次（只設最新的那個）。播放中照舊。
2. **還沒準備好先畫縮圖**：影片元素 `ready` 為 false 而且這個圖層還沒有任何畫面（或上一格是別的時間點超過 1 秒）時，用 H3 的 `thumbFallback`（素材縮圖依時間挑最近一張）頂著，`seeked` 後換回影片畫面。這樣往回拖時至少看得到大概的畫面，不會只剩白框。
3. **預設順暢**：`readQuality()` 沒存過的時候回傳 `'smooth'`（不是 auto）；設定頁三個選項保留。
4. **頂列切換**：編輯器頂列比例按鈕（`9:16`）旁邊加一個小按鈕，顯示「順暢」或「高清」，點一下切換（存 `vc-preview-quality`），重建預覽。e2e：點了畫布長邊 480 ↔ 960。
- 驗收：e2e 模擬「往回拖」：連續 20 次 `seekTo` 往回（每次 0.1 秒），每次都取樣預覽，不能出現全黑（素材是純色影片）；`seeked` 之前有縮圖。🔴 iPhone 真機必測。

## I4. 標記編輯器：播放預覽＋白線＋多組起迄（3、圖六）
參考 VideoClip_2 的 `AudioRangeEditor`／`SourceRanges`，把現在的 `TrimPanel`／`RangePicker` 改成：
- **上面一個預覽畫面**（高 160px）：影片素材＝直接用一個自己的 `<video>`（素材本身，不經過整個專案的合成，才不會卡）；音樂＝整個專案那一刻的畫面（從預覽畫布複製）。
- **白線**（目前位置）：在縮圖／波形條上畫一條白色直線；按「▶ 播放」時白線跟著跑（`requestAnimationFrame` 讀 `currentTime`）；點條上任何地方＝白線移過去並暫停。
- **在白線新增標記**：「＋ 在白線加一段」＝從白線開始放一段（到下一段開頭或 1 秒），可以有好幾段；每段上方一對小旗標可拖；選到的一段可刪。旗標拖的時候白線跟著到那個位置（預覽畫面同步）。
- **影片**：完成時跟現在一樣（多段＝拆成多個片段、留在原位）。
- **音訊／影片原音**：多一個模式「靜音標記」：在同一個片段裡標出好幾段要靜音的地方（**不拆片段**）。資料：`VideoItem.audioRanges?: [number, number][]`（素材秒數，保留聲音的範圍；沒有＝全部保留）。預覽：`Player.syncVideo`／`syncMusic` 播到不在範圍裡的時間就把那個元素的音量設 0；匯出：`mixAudio` 依 `audioRanges` 把範圍外補零。音訊分頁每一列都有「修剪」（音樂＝修剪＋靜音標記；影片原音＝只有靜音標記）。
- **名稱**（3）：音訊列、修剪面板標題都用 `itemTitle`（有命名就是命名，不顯示檔名）；「分離原音」產生的音樂片段沿用那支影片的命名與首圖（`separateAudio` 時複製 `label`，列表顯示「♪ 原音・<命名>」＋那支影片的首圖）。
- 驗收：e2e——白線在播放時移動（兩個時間點位置不同）；點條上移動白線；在白線加三段；音訊靜音標記兩段後匯出的那兩段 `audioPeaks` 很小、其他正常；名稱顯示命名。

## I5. 單一影像的進場／出場特效；版型＋特效（13、5）
- 資料：`VideoItem.effectIn?: { kind: TransitionKind; duration: number }`、`effectOut?`（字卡 `TextItem` 也加，文字也能進出場）。
- 算法：用同一個 `transitionFrame(kind, p)`。進場：A＝空、B＝這個物件，p 從 0 到 1（物件開始後 0～duration 秒）；出場：A＝這個物件、B＝空。只取那一個物件的 Look（位移、縮放、透明度、裁切、模糊），顏色層只蓋在這個物件的範圍（用物件的方框當 `rect`）——不影響別的圖層。
- **版型**：外框的 `effectIn／effectOut` 套用到整組（各格、色塊、外框一起動，用整組的中心當縮放中心）。
- 介面：
  - 特效分頁選到物件時分三塊：**進場**、**出場**（任何影像、貼圖、字卡都有）、**轉場（跟前一段）**（只有前面緊接著另一段時才有）。三塊共用同一組 A→B 示意卡片（進場的卡片畫「空→B」、出場畫「A→空」）。
  - 版型面板：選版型 → 選外框顏色 → **選進場特效、出場特效（可「無」）** → 選照片影片（VideoClip_2 的流程）。原本的「捲動／滑入滑出」動畫保留在版型整體面板，但放在進出場特效下面。
- 驗收：單元——進場 p=0 時物件看不到、p=1 時完整；e2e——照片設「捲簾放下」進場，開始後 0.1 秒上半有、下半沒有；版型設「左移」出場，結束前整組往左。

## I6. 裁切筆刷偏移（9）
參考 VideoClip_2 `cropPointer.ts`：
- 筆刷／橡皮擦模式：手指按下的地方畫一個**白色實心小圓 A**（手指位置）；真正畫的地方是**焦點圓**（空心圓＋十字），在 A 的上方「距離」px（預設 70px），手指移動時兩個一起移動。
- 工具列第二列：「粗細」（焦點圓大小）＋「距離」（0～150px；0＝直接畫在手指下面）。
- 按下時先只移動、不畫（避免一按下去就在錯的地方畫一點）：手指移動超過 4px 才開始畫，或按住 250ms 後開始。
- 驗收：e2e——距離 80px，手指在 y 畫一條線，被擦掉的是 y−80px 那條（取樣遮罩）。
