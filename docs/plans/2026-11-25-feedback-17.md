## 已查到的事實（Opus）
- **拉長（`kinetic/fx/in.ts` 的 `stretch`）的動畫是一直循環的波浪**：第 j 個字的拉長量 `sin(t*3.6 − j*0.75)` 的正半週，週期約 1.75 秒，跟「一輪」（`len = 4.2 秒 × 詞數`）無關。6 個字時相位差 5×0.75＝3.75 弧度，比半週（π）還大，**任何時刻都至少有一個字在被拉長**，所以 `holdTime`（0.56 × 4.2 ＝ 2.35 秒）停下來那一格剛好是第二波的開頭：蔡、氏被拉長。字少（3 個字）時看不出來，字多就會。
- **邊緣淡出（`kinetic/core.ts` 的 `fadeEdges`）只把框的上下（或左右）各 12% 擦掉**。框比字大很多時（使用者的框：字在中間、上下都留很多空），字根本碰不到那 12%，所以看起來沒作用。底色（`bg`）有設的時候才看得出來。功能本身是對的，但範圍太窄、看不到在哪裡淡。

## Z22 動態字卡「播過的字乖乖待著」（使用者決定，2026-11-25 晚）
使用者的原則：**一個字（或一張卡、一個色塊）的動畫播完之後，就以它最後的樣子靜靜留在自己的位置**——樣式（卡片、色塊、顏色、排版）保留，只是不再動來動去，表示「這個字已經播過了」。〔停在最後畫面〕停下來的那一格＝整句都播完、全部乖乖待著的樣子（不是回到無特效的一般字卡）。播放中也照這個原則（不只停格那一格）。

做法分四類（實作時先產生對照圖確認每一式屬於哪一類，再逐式改）：
1. **逐字／逐張出現**（逐字重擊、逐字踩拍、逐字蹦跳、翻牌看板、翻卡、拉霸、跳錶、打字機、跟唱填色、橫條拼字、色塊揭開、散開聚合…）：改成**累積**——第 n 個字重擊（翻開、掉下來…）到**它在整句裡的位置**後留著，變成靜止的樣子；最後是整句排好的樣子。以逐字重擊為例：整句先算好每個字的位置（跟無特效時一樣排一行，太長自動縮小），第 n 個字從放大 2.4 倍＋旋轉砸到自己的位置，之前砸完的字留在原位、不再動。
2. **一直在動**（拉長、波浪起伏、抖動、霓虹燈管、訊號故障、重影抽搐、燈泡將熄、字距拉開、對焦…）：每個字的動作只做一輪（例如拉長：波浪從第一個字掃到最後一個字，每個字拉一次就回到原狀留著），一輪最後全部靜止。
3. **會飛走／消失**（穿過去、衝向鏡頭、融化拉長、往下滴、慢慢逼近、字被換掉、手電筒…）：〔停在最後畫面〕停在字完整、還沒開始離開的那一刻（`hold`）；播放中照原本（〔重複播放〕時才有「離開」那段）。
4. **一直流動、沒有一輪**（巨字橫移、直排對流、重複波浪、斜帶、彎道、多層跑馬燈、遠近直書、交叉封條、透視字幕、環繞、點陣看板、歌詞捲動）：〔停在最後畫面〕時，跑到整句在畫面上完整、最清楚的那一刻停住（照現在的 `poster`，但要確認整句都在框裡；不在的式子另外算一個停的時間）。
- **〔重複播放〕**：一輪＝整句播完＋全部靜止停留一下（約 0.8 秒），然後重新開始。
- **多個詞**（字卡換行分成好幾個詞的式子）：照原本一個詞一輪；每一輪裡照上面的原則；停格停在最後一個詞播完、靜止的樣子。
- 一輪長度跟字數有關的式子，`len` 改成依字數算（字多就長一點），`hold` 指到最後一輪全部靜止之後；寫一個共用工具 `roundAt(words, t, D)`（`core.ts`）找出現在是第幾個詞、這一輪裡的時間。
- **對照圖**（先做）：e2e 產生 `docs/screenshots/feedback-17/hold-sheet-before.png`（所有式子用「蔡氏家族聚餐」各畫 `holdTime` 那一格），改完再產生 `hold-sheet-after.png`；PROGRESS 列出每一式歸在哪一類、改了什麼。
- 測試：單元測試——重擊排字在 `holdTime`：6 個字都畫出來、各在自己的位置（記錄 `drawWord` 的呼叫：6 次、x 由左到右、縮放都是 1、旋轉都是 0）；拉長在 `holdTime`：6 個字 `sx`＝`sy`＝1；12 個字也一樣；每一式 `hold ≤ len`。e2e：重擊排字播放中途（第 3 個字砸下來時）前兩個字還在畫面上；逐字重擊照舊（同一時間只有一個字）。
- **逐字重擊例外（使用者選 A）**：原本的〔逐字重擊〕（`hit`，一字一字在同一個位置出現、下一個字取代上一個）**維持原樣**，停格照舊停在最後一個字砸好的那一刻。另外**新增一式〔重擊排字〕**（`hitline`，登場組，放在逐字重擊後面）：做法就是上面第 1 類的例子（整句先排好位置，第 n 個字從放大 2.4 倍＋旋轉砸到自己的位置後留著不動；字多時整句自動縮小成一行，超過 8 個字換第二行）；示意縮圖（`poster`）停在砸到第 4 個字左右的那一格；`len`＝字數 × 0.42 ＋ 0.8（最後全部靜止停留）；`hold`＝最後一個字砸好之後。跟逐字重擊共用砸下來的那段動畫（抽成一個函式）。`'hitline'` 要加進 `model/types.ts` 的 `KineticId`、`kinetic/index.ts` 的登錄表；這是第 65 式，註解裡的「64 式」順便改成「65 式」；`kinetic.test.ts` 裡數量相關的檢查跟著改。
- 其他逐字類（翻卡、翻牌、逐字蹦跳、逐字踩拍…）照「播過的字乖乖待著」**直接改**，不另外留舊版。
- 先做：〔重擊排字〕（新增）、拉長、翻卡、翻牌、逐字蹦跳、逐字踩拍＋對照圖；看過使用者回饋再改其他式子。

## Z27 轉場不重播（讓藏起來的 `<video>` 先對好時間）
1. **量測先行**：效能框「最近轉場」多三個數字：`起跑` B 的 `play()` 到真的開始動花了幾毫秒（`playing` 事件或 `currentTime` 開始變）；`交棒差` 換手範圍結束、改顯示 `<video>` 那一刻差幾秒（正＝落後）；`A 落後` A 進換手範圍時差幾秒。`debug.ts` 加 `setPlayLatency(ms)`：讓影片池的 `<video>` 的 `play()` 晚 ms 毫秒才真的開始（沙盒的 Chromium 不會慢，用這個模擬 iPhone）。
2. **起跑延遲估計**：Player 記最近幾次 `起跑` 的中位數 `lat`（預設 350 ms，夾在 100～800 ms），下面兩項都用它。
3. **藏起來時預約對時（B）**：B 的 `<video>` 沒在畫面上（轉場前暖機、或轉場中用預解圖顯示）而且它的聲音還很小（轉場聲音倍數 ≤ 0.3；暖機本來就靜音）時，差超過 0.04 秒就：暫停 → seek 到「目標＋lat＋0.25 秒」→ seek 完、時鐘走到「那個時間 − lat」時才 `play()`；開始動之後再量一次，還差就再來一次（最多 3 次）。取代這段時間原本的硬跳／保護期邏輯（`videoSyncPlan` 加 `hidden` 輸入，純函式回傳 `{ pause, seekTo, playAt }`）。
   - B 入點在 0（轉場前停在第一格）：不等時間到才 `play()`，在「還差 lat 秒到 0」時就 `play()`（提前起跑）。
4. **交棒不往回跳（保險）**：
   - B 的預解範圍再延長到轉場結束後 2.0 秒（`HANDOVER_AFTER` 2.0；照舊受 `MAX_FRAMES`／160MB 預算限制，超過就縮短）。

現況：流動時是一條很長的 S 形白帶、上面「蔡氏家族聚餐・蔡氏家族…」重複、字往左上流；收尾時另一條只寫一遍字的短緞帶從別處飛進來。改成**整個特效只有一條緞帶**：長度＝整句字一遍＋左右留白（L）、字黏在緞帶上、從頭到尾不變。

1. **流動（一直播的時候）**：這條緞帶沿著原本的 S 形路線**順著讀字的方向**滑過去（從看得到的左邊外面進來、往右下、從右邊出去），「餐」在前面；出去之後再從左邊進來（一輪＝穿過看得到的那段 S 約 1.8 秒）。不再有重複的字、不再往左上流。
   - S 路線只取「畫面看得到的那一段」（直式畫面只看得到中間一小段）＋兩端各延伸 L 到畫面外，速度＝這段長度 ÷ 1.8 秒。
2. **〔停在最後畫面〕（緞帶第一次滑到畫面中間時開始，約 0.9 秒）**：緞帶**照原本的方向和速度**繼續往右下走、離開 S，被風帶著繞一圈（往右下 → 下方往左 → 左邊往上 → 沿著中心線往右），減速停在正中間、風停、拉直成橫條；往右走時「餐」在前，停下來剛好從左讀到右。
   - 緞帶像蛇一樣跟著頭走（`ribbonShape`），加上從頭往尾傳的風的波浪；頭走的距離用三次 Hermite：起點速度＝滑過 S 的速度、終點 0（不會突然變快變慢）。
   - 大小：流動時跟收尾時都用同一個大小（緞帶要放得進直式畫面：整句寬度 ≤ 看得到寬度的 68%），**全程不縮放**。
   - 範圍：水平＝字卡框跟畫面重疊的部分；垂直＝以框的中心線為中心、上下對稱，取「中心到看得到的上緣、下緣」比較近的那個（字卡放在影片下方的黑色區時，只在黑色區上下飄，不跑到影片後面或畫面外）。`renderKinetic` 算出框在畫面上看得到的範圍傳給 Stage（`vis`，框內像素）。
3. **不跳格**：字卡定義 `smooth: true`（彎道）**流動和收尾都**用真正的時間畫（不量化成 1/30、1/60 秒的步），播放時每秒畫 60 次。
- 時間：`hold` ＝緞帶中心第一次到畫面中間的時間（約 0.9 秒）＋收尾 `settleLen` 2.3 秒。
- 卡片縮圖（特效分頁的預覽）也改成這個樣子（一條緞帶滑過 S）。
- 測試：
  - 單元測試：任何時間畫出來的字都只有一遍整句（`fillText` 的字數＝句子字數）；流動時緞帶中心沿 S 等速前進、每輪頭尾接得上；收尾開始那一刻前後 1/60 秒緞帶上每個字位移 < 1.5 單位（接得上）、頭的速度連續；長度固定；飄的時候都在範圍內（直式、橫式、框往下移到 y=0.8）；q=1 是正中間橫條、「蔡」在左；`renderKinetic` 的 smooth 式子差 1/120 秒的兩個時間畫出來的鍵不一樣。
