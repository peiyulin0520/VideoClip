## 待使用者選擇的規劃

### 3. 貼圖改用 IG 同款來源（GIPHY）

- IG 限時動態的 GIF 貼圖來自 **GIPHY**。可以接 GIPHY API：搜尋（中英文關鍵字）＋熱門貼圖，**會動的透明貼圖**。
- 需要：
  - **GIPHY API key**：免費的開發用 key 每小時 100 次搜尋；正式 key 要向 GIPHY 申請審核，並在介面標示「Powered by GIPHY」。key 會出現在網頁程式裡（GIPHY 允許，但可能被別人濫用額度）→ 建議做成「設定頁貼上自己的 key」，或用專案的開發 key 先試。
  - 隱私：只會把**搜尋關鍵字**送到 GIPHY，不會上傳影片（符合 AGENTS 規則 5）。
  - 技術：目前圖層只會畫靜態圖。要支援「會動的貼圖」：下載 GIPHY 的動態 WebP/GIF，解成每一格（優先用瀏覽器的 `ImageDecoder`；iPhone Safari 不支援時用 MIT 授權的 GIF 解碼函式庫），依時間播放；匯出時照時間取格。
- 步驟：G1 搜尋＋熱門＋加入第一格（靜態）→ G2 會動的貼圖（預覽＋匯出）→ G3 最近用過、收藏。
- 現有 397 個 Fluent Emoji 保留（不用網路、不用 key）。

### 4. 人物去背影片（只留人）

兩種做法，可以都做：
- **A. 一鍵自動去背（建議先做）**：用 Google MediaPipe 的人像分割模型（Apache-2.0，模型幾 MB，放在我們網站上），**在手機上本機計算，不上傳影片**。影片每一格算出人的輪廓，背景變透明，就能疊在別的影片上（例如 VLOG「人頭在 O 裡」）。另外給「邊緣柔化」「範圍擴大／縮小」滑桿。缺點：頭髮、手邊緣不一定乾淨；iPhone 上的速度要真機測（預覽可能先用較低解析度）。
- **B. 手動描邊（原本規劃的 R16）**：在畫面上用手指圈出要留下的範圍；人會動的話，在幾個時間點各調整一次輪廓，中間自動補間。適合非人物或要很精準的時候。
- 匯出時一格一格套用遮罩，預覽與匯出用同一套。
- 步驟：C1 自動去背（單支影片）＋邊緣調整 → C2 手動描邊＋關鍵影格 → C3 「人頭 O」模板（搭配字卡）。

### 6. 介面主題（背景風格）

- 設定頁「介面風格」：**深色**（目前）、**黑白**（純黑白灰、點綴色也變灰黑）、**清新**（白色基底、淺灰卡片、淡粉／薄荷點綴）、**溫暖**（奶茶棕、米色卡片、焦糖色點綴）。可選「跟手機設定（淺色／深色）」。
- 只換 App 介面，**不影響影片內容與匯出**；預覽畫面外圍維持深色（看影片顏色才準），可選。
- 做法：目前很多顏色寫死在 CSS（`#222`、`#2a2a2e`、`#111`…），先全部換成變數（底色、卡片、按鈕、文字、次要文字、線條、強調色），再用 `data-theme` 切換；選擇存在這台裝置（localStorage）。e2e：切換後各處顏色改變、四種主題截圖給使用者挑。
- 工作量最小，可以最先做。
