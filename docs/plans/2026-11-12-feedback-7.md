## G1. 文字透明度、字塊預設透明、分頁層級（使用者 1、2、4）

### G1-1 文字透明度與樣式一致（1）
**先查原因（Sonnet 實作前做）**：用 e2e 重現「兩個字卡，一個改顏色」，比對兩個字卡的 `card.runs[0]`（`color`、`strokes`、`shadow`、`weight`）與 `transform.opacity`、`blend`。預期原因是下面其中一個，**查到哪個就在日誌寫哪個**：
- 第二個字卡是從「＋新增」建立的，預設樣式跟第一個不同（例如沒有描邊）；
- 在圖層分頁調了「透明度」或「混合模式」（圖層的 `transform.opacity`／`blend`），字看起來變淡；
- 顏色本身是深青色，在照片上對比低。

**做法**：
1. 文字分頁 → 文字：顏色下面加「**文字透明度**」滑桿（10–100%），存在 `TextRun.opacity`（選填，預設 1）。`src/engine/textRender.ts` 畫字（含描邊、陰影）時乘上這個透明度；字塊、裝飾各自有自己的透明度，不受影響。
2. 文字分頁 → 文字：加「**套用這個樣式到所有文字**」按鈕：把這個字卡的字體、大小、顏色、透明度、粗細、描邊、陰影複製到專案裡**所有其他字卡**（不動文字內容、位置、字塊、裝飾）；一步復原；跳提示「已套用到 N 個文字」。
3. 新增文字時：預設樣式改成「**上一次新增或編輯的字卡的樣式**」（存在專案的 `lastTextStyle`，沒有就用目前的預設），這樣新加的字不會跟之前的不一樣。
4. 圖層分頁的「透明度」改名「**整個圖層透明度**」，旁邊一行小字「文字本身的透明度在文字分頁」，避免兩個透明度搞混。

### G1-2 字塊預設透明（2）
- `DEFAULT_BOX`（`src/app/editor/TextPanel.tsx`）改成 **不填滿**（`fillOn: false`），選了形狀後只看得到**細框線**（`stroke: { color: 目前文字顏色, width: 3, opacity: 1 }`），讓使用者看得出形狀；要填滿到「填滿」區打開、選顏色。
- 形狀縮圖（`ShapeThumb.tsx`）改成**線框**（用 `--fg` 顏色描邊、不填滿），不要粉紅實心。對話框、星形、標籤箭頭同樣。
- 舊字卡不動（已經存的粉紅色字塊維持原樣）。
- 「獨立圖形」（文字分頁沒選字卡時的「＋ 新增圖形（星形、對話框、雲朵…）」、字塊頁最下面的「＋ 另外新增一個獨立圖形」，`createShapeItem`）：**使用者 2026-11-12 選 C：改成透明底、棕色外框線**（附 VideoClip_2 的截圖當樣子：形狀只有一條約 3px 的棕色線、裡面透明）。預設 `fillOn: false`、`stroke: { color: SHAPE_LINE, width: 6, opacity: 1 }`（以 1080 寬為基準，手機上看起來約 2–3px）；`SHAPE_LINE = '#8b5a44'`（溫暖主題的棕色，跟主題無關、固定這個顏色，因為它會被匯出到影片裡）。舊的黃色星星不動。
- 字塊（G1-2）選形狀時的預設框線也用同一個棕色 `SHAPE_LINE`（不要用文字顏色，白字時框線會看不到），兩者一致。
- 形狀縮圖也照截圖：棕色線框、透明底（縮圖的線用 `SHAPE_LINE`，在暗黑主題下也看得到）。
- 參考截圖的第 3 層分類按鈕（無字塊／基本）選中是**米色底＋下方一道棕色陰影**，跟第 2 層選中的磚紅色實心明顯不同——G1-3 的第 3 層可以直接用這個樣子（比外框膠囊更明顯），Sonnet 擇一，兩種都要過「第 2、3 層選中樣式不同」的測試。

### G1-3 分頁三層級（4）
目前三層看起來一樣。改成：
| 層級 | 例子 | 樣式 |
|---|---|---|
| 第 1 層：底部分頁 | 剪輯／疊加／文字… | 維持：文字＋底線（不變） |
| 第 2 層：面板裡的區塊 | 文字／版面／字塊／描邊陰影／裝飾 | **分段控制**：一整條淺色底（`--btn2`），選中的那段是白底（`--panel`）＋陰影，字是 `--fg`，**不用強調色** |
| 第 3 層：分類 | 無字塊／基本／對話框… 、貼圖分類 | **小外框膠囊**：透明底、1px `--border` 框、字 13px；選中＝強調色框線＋強調色字（不填滿） |
- 「＋新增」不再跟第 2 層同一排長得一樣：改成第 2 層右邊的**圓形 ＋ 圖示按鈕**（`aria-label="新增文字"`），或移到面板最上面一行。
- 共用元件：新 `src/ui/Segmented.tsx`（第 2 層）、`src/ui/ChipTabs.tsx`（第 3 層），文字面板、貼圖分類、版型分類都換成這兩個。

### G1-4 專案封面可以自訂（使用者 2026-11-12 追加）
現況：首頁專案卡片的封面＝第一個影片／照片的第一張縮圖（`Home.tsx` 的 `coverOf`），沒有素材就是一個底色。
做法：
1. 資料：`Project.cover?: string`（JPEG data URL，長邊 480px，約 30–60KB；只存在專案裡、不另存素材）。`coverOf` 先看 `cover`，沒有才用第一個素材的縮圖。
2. **首頁卡片的「…」選單**多一個「**更換封面**」→ 下方面板三個選項：
   - 「**從影片選一格**」：一條橫向的縮圖帶（所有影像素材的 `thumbs` 依時間排），點一張＝用那張；
   - 「**從相簿選照片**」：`<input type=file accept="image/*">`，讀進來縮成長邊 480px 的 JPEG；
   - 「**恢復預設**」：刪掉 `cover`。
3. **編輯器**：點頂列的專案名稱（現在是改名）出現的面板裡，多一個「**用目前預覽畫面當封面**」：抓預覽畫布這一格（Pixi `renderer.extract.canvas`，縮成長邊 480px JPEG）。一步復原（`cover` 是專案欄位，走 `apply`）。
4. 複製專案時封面一起複製；專案改比例不影響封面。
- 驗收：e2e：選單「更換封面」→ 從相簿選 `photo.png` → 卡片封面變成那張（`background-image` 是 data URL、取樣顏色）；重新整理還在；恢復預設 → 回到第一個素材縮圖；編輯器「用目前預覽畫面當封面」→ 回首頁封面是那一格的顏色（純紅測試影片取樣紅色）。

### 驗收
- 單元：`textRender` 透明度 0.5 時字的像素 alpha 約一半；「套用到所有文字」只改樣式欄位。
- e2e：兩個字卡、一個改成半透明 → 預覽取樣顏色變淡；按套用 → 另一個也變一樣（比對 `runs[0]` 樣式欄位）、一步復原；選字塊「方形」→ `box.fillOn === false`、有框線；形狀縮圖不是粉紅色（取樣）；第 2 層與第 3 層選中按鈕的背景色不同（`getComputedStyle`）。
- 要改的既有 e2e：`phase3a-shapes`、`box-fill-border`、`phase3a-panel` 等預期「選形狀後是粉紅色填滿」的地方。

## G2. 時間軸收合、軌道變細（使用者 3）

### 做法
1. 時間軸預設「**收合**」：只顯示
   - 最下面那條影像軌（主要影片，高度 44px，原本 64px）；
   - 其他每一區各縮成**一條細的摘要列**（高度 18px）：例如「字卡 ×6」「貼圖／疊加 ×2」「音樂 ×1」——那一區所有物件畫成細細的色條疊在一起（看得到大概的時間位置），點不到單一物件；
   - **選取中的物件所在的軌道一定展開顯示**（這樣在預覽上點了字卡，時間軸上還是看得到、拖得到它）。
2. 時間軸左上角（軌道圖示那一欄最上面）加「**▾ 圖層（9）**」按鈕：點了切換「收合／展開全部」；展開時每條軌道高度 **32px**（原本 44px），最下面那條影像軌 44px。記住在這台手機（`localStorage vc-tl-expanded`）。
3. 點摘要列＝展開那一區（其他區維持收合）。
4. 隱藏的軌道（眼睛關掉）在收合時不顯示，在摘要列的數字旁邊顯示「（2 條隱藏）」。
5. 長按拖移素材（F5）時，如果目標區是收合的，拖到摘要列上方停 0.6 秒自動展開那一區（像資料夾）。
6. 軌道圖示（左欄）寬度從 44 → 36px；片段上的字 11px 不變；縮圖在 32px 高時仍顯示。

### 動到的檔
`src/app/editor/Timeline.tsx`（`layout` 計算加收合狀態、摘要列）、`styles.css`。

### 驗收
- e2e：6 條字卡＋2 條影像＋1 條音樂 → 預設時間軸高度 < 展開時的一半；摘要列顯示「字卡 ×6」；點「圖層」展開 → 9 條都在、每條高 32px；重新整理後記住；選一個字卡 → 那條字卡軌在收合時仍顯示；長按拖到收合的摘要列停留 → 展開。
- 要改的既有 e2e：所有用 `[data-testid="track"]` 數軌道、找片段的測試（`track-drag`、`clip-drag`、`media-tracks`、`preview-first` 的「多條軌道全部顯示」）——在測試開頭展開（helper `expandTimeline(page)`）。


### G2 補充（使用者 2026-11-12 回覆，參考圖：使用者另一個工具「小白剪輯台」的時間軸）
參考圖重點：時間軸左邊是文字的列名「影像／字卡／轉場」；影像列的每一段是一個色塊，上面寫「**1 開場・揮手**」「**2 蛋糕前**」「**3 抓周**」和長度「0:04.2」；字卡列每段一個短標籤；**轉場列**在兩段影片交界的位置有一個**小圓圈**，圈裡是轉場代號一個字（例如「簾」「淡」），**目前選取／正在看的那個是紅底白字，其他是白底紅字**。

1. **片段可以自己命名**（`ItemBase.label?: string`，選填）：
   - 選到片段 → 剪輯分頁多一個「命名」工具（`Pencil` 圖示）→ 跳出輸入框（預設是目前的名字，空白＝不命名）；時間軸上**連點兩下片段的文字**也可以改。一步復原。
   - 時間軸展開時，影像片段上顯示「**序號 名稱**」＋第二行長度（例「1 開場・揮手 / 0:04.2」）；序號＝這條軌道上依開始時間的順序（1、2、3…，自動算，不存）。沒有命名＝「1 影片 4.2s」。字卡片段沒命名時照舊顯示文字內容。收合時（摘要列）不顯示名字。
   - 「查看圖層」清單（F2）、音訊分頁的列表也用這個名字。
2. **軌道也可以改名**：軌道選單（點軌道圖示）多一個「改名」；收合時摘要列用區名（影像／字卡／音樂）。展開時左欄寬度夠的話（≥ 360px 螢幕）顯示**軌道名稱文字**而不是只有圖示（例「影像 1」「字卡 2」），手機太窄就維持圖示＋名字縮寫。
3. **轉場小圓圈**（跟 G5 一起做，G2 先留好位置）：最下面那條影像軌的下方多一條細的「**轉場列**」（高度 22px，沒有任何相鄰片段時不顯示）；每兩段**首尾相接**的片段交界處一個 20px 小圓圈：
   - 沒有轉場：灰色虛線圓圈「＋」；點了＝選這個交界、切到特效分頁選轉場。
   - 有轉場：圓圈裡是**代號一個字**：淡（淡入淡出）、黑（黑場）、白（白閃）、閃（暖色閃光）、推（左推）、升（上推）、縮（縮放）。
   - **目前選取的轉場：紅底（`--accent`）白字；其他：白底（`--panel`）、強調色字＋強調色框**（照使用者的例子；顏色跟著主題）。
   - 其他影像軌（疊加的）交界也可以有轉場，圓圈畫在那條軌道片段的下緣。
- 驗收補充：e2e 命名一個片段 → 時間軸顯示「1 名稱」、重新整理還在、復原；兩段相接 → 轉場列有「＋」圓圈 → 點了到特效分頁 → 選白閃 → 圓圈變「白」、紅底（選取中）→ 點別處 → 白底。

## G3. 音訊分頁改版＋片段選取用「上方小旗標」（使用者 5）

### G3-1 音訊分頁（參考 VideoClip_2 的 `AudioPanel`）
音訊分頁列出**專案裡所有的聲音來源**，每一列：
- 名稱（♪ 音樂檔名／🎬 影片的原音「影片 2.0s」）、在時間軸的位置（0:03–0:07）；點名稱＝選取並跳到那裡；
- 「**保留聲音**」開關（影片原音：關掉＝這段影片靜音；音樂：關掉＝靜音）；
- 音量滑桿（0–200%）；
- 影片原音多一個「**分離原音**」：把這段影片的聲音複製成一段音樂軌上的音訊（同一個素材、同樣的 trimIn／長度／位置），影片本身改成靜音——之後可以單獨移動、修剪、刪除原音。（Asset 已有 `hasAudio`，音樂軌的 `type:'audio'` 物件可以直接指向影片素材，`mediaPool`／`exporter` 要確認 audio 物件的素材是影片檔也能播／混音。）
- 上面保留「＋ 加入背景音樂」「全部影片靜音」。

### G3-2 片段選取：上方小旗標、可多段、顯示當下畫面
適用：修剪面板（影片、音樂；`TrimPanel.tsx`），以及 G4 版型格子的片段選取。
1. **不要兩側拉霸**。整段素材攤開成一條縮圖帶（音樂是波形），**上方**一條 20px 高的「旗標列」：
   - 每一段保留的片段＝一對旗標：起點旗標「⎡」、終點旗標「⎤」（小小的、強調色、底下有一條細線指到縮圖帶）。手指按住旗標左右拖＝改這一段的起點／終點；旗標的觸控區 44×44（看起來小、按起來大）。
   - 保留的片段：縮圖帶正常顏色；沒保留的：變灰（`filter: grayscale(1) brightness(0.55)`）。
2. **多段**：旗標列右邊「＋ 加一段」：在播放頭附近、沒有被選的地方加一對旗標（預設 1 秒）；點一對旗標中間的色條＝選取那一段，出現「刪除這段」。至少要留一段。
   - 音樂、影片都可以多段（影片多段＝把同一支影片切成幾段，中間不要的拿掉）。
   - 套用（按「完成」）時：一段＝跟現在一樣改 `trimIn`／`duration`；**多段＝把這個物件換成 N 個物件**，每段放在「它在原本片段裡的時間位置」（`start = item.start + (段起點 − item.trimIn) / speed`），中間不要的地方變成空位（音樂就是那段沒聲音、影片就是空位）；旁邊出現「補齊空位」按鈕可以讓它們接起來（用 F4 的 `closeGap`）。一步復原。
3. **顯示當下畫面**：縮圖帶上方（旗標列的上面）一個小預覽 **96×170**（照專案比例），顯示「正在拖的旗標那一秒，整個專案合起來的畫面」（不是素材本身）——拖音樂的旗標時就看得到那時候影片在演什麼。做法：拖旗標時 `player.peek(時間)`，再把預覽 canvas 縮小畫到這個小 canvas（Pixi 的 `renderer.extract.canvas` 或在 render 之後立刻 `drawImage`；**要確認 iPhone 上 WebGL canvas 的 `preserveDrawingBuffer`**，不行就用 `renderer.extract`）。
4. 舊的「前面少／多 1 秒」按鈕保留在最下面一排（精準微調）。

### 資料
- 不新增欄位：多段直接變成多個物件。
- `src/engine/timeline.ts` 新純函式 `splitByRanges(item, ranges)` → 物件陣列（可單元測試）。

### 驗收
- 單元：`splitByRanges`：一段、兩段、三段、段落重疊會合併、超出素材範圍會夾住、變速片段。
- e2e：音訊分頁列出背景音樂＋每支有聲音的影片；關掉一支影片的「保留聲音」→ 匯出沒有那段聲音（沿用 `music.spec` 的 `inspect`）；分離原音 → 音樂軌多一段、影片靜音；修剪面板沒有拉霸、有旗標；拖起點旗標 → trimIn 改變；加一段 → 完成 → 變成兩個物件、位置正確、一步復原；拖旗標時小預覽有畫面（取樣不是全黑）。
- 要改的既有 e2e：`trim.spec`（修剪面板的把手 testid 改成旗標）、`music.spec`（修剪面板、音量面板的位置）。

## G4. 版型變成「一個整體物件」（使用者＊膠卷）

### 現況與問題
目前（L1）一個版型＝外框（鎖住的影像軌）＋每格一條影像軌的一個物件，各自獨立：
- 在預覽上點到的是**格子**，縮放的是格子 → 會跑版；
- 整個版型不能一起縮放移動；
- 每格長度不一定一樣。

VideoClip_2 的做法：整個版型是**一條軌道上的一組物件**（`track.template`），共用同一段時間；外框是程式畫的（膠卷齒孔）；動畫有「捲動（drift：由下往上）」「滑入滑出（slide）」。我們照這個方向，但做成**一個物件**，比較好縮放。

### 新資料：版型物件 `TemplateItem`
```ts
type TemplateCell = {
  rect: Rect;                // 格子在版型裡的位置（0–1，版型本身的座標）
  fill: 'black' | 'white';   // 素材不夠長時，剩下的時間顯示的顏色
  clips: CellClip[];         // 這一格依序播放的片段（可以中間穿插色塊）
  audible: boolean;          // 這一格出不出聲（預設只有第 1 格）
  crop?: Crop;               // 素材在格子裡的裁切（預設置中填滿）
};
type CellClip = { assetId: string; at: number; trimIn: number; duration: number; speed: number; volume: number };
// at：在版型時間裡的起點（0 ~ 版型長度），沒有片段的時間＝fill 色塊
type TemplateItem = ItemBase & {
  type: 'template';
  layoutId: LayoutId;        // 沿用 layouts.ts 的 8 種
  frameColor: string;
  motion: 'none' | 'drift' | 'slide';   // 捲動（由下往上捲過畫面）、滑入滑出
  cells: TemplateCell[];
};
```
- `Item` 聯集加 `TemplateItem`；放在**影像軌**（`trackKindOf` 回傳 `media`）。
- `transform`（x、y、scale、rotation、opacity）是**整個版型**的；格子跟著一起縮放、移動、旋轉。
- 版型長度＝`duration`；**每一格的總秒數都是這個長度**（使用者要求「每一素材總秒數要一樣」）。素材比較短：片段後面接 `fill` 色塊；素材比較長：只用前面一段（之後可以調）。

### 畫面（scene／compositor）
- `buildScene`：版型物件展開成：外框圖層（沿用 `layouts.ts` 產生的有洞 PNG，加上膠卷款的齒孔；可以用 VideoClip_2 那樣程式畫）＋每一格一個圖層（那一秒在播的片段的影片／照片，或 `fill` 色塊）。每一格的方框＝`cell.rect` 經過「版型 transform」換算到畫面；`motion` 再加位移（drift：y 由 +0.35 到 −0.35 個畫面高；slide：開頭 0.8 秒從右滑入、結尾 0.6 秒往左滑出，跟 VideoClip_2 相同的曲線）。
- 影片池：每格的片段用 `itemId + ':' + cellIndex + ':' + clipIndex` 當 key 借 `<video>`；同時播放上限沿用（超過 5 支提示）。
- 聲音：只有 `audible` 的格子出聲；匯出混音一樣。

### 操作
1. **預覽上點版型**：選到**整個版型**（選取框是整個外框）；拖移、雙指縮放旋轉都是整個版型。**不能**單獨縮放格子。
2. **選格子的片段**：版型被選取時，再點一下某一格 → 那一格「**被聚焦**」（格子邊框變亮、其他格變暗），版型分頁顯示那一格的**片段軸**（G3 的上方旗標，範圍是「素材時間」，下面另外一條「版型時間軸」顯示片段放在哪、色塊在哪）。點預覽空白或按「完成」離開聚焦。
3. **版型分頁**（選到版型時）：
   - 外框顏色、動畫（無／捲動／滑入滑出）、版型長度（秒，滑桿 1–30）；
   - 每一格一列：縮圖、「換素材」、「這格出聲」開關、「色塊顏色 黑／白」、展開＝這格的片段軸；
   - 片段軸（版型時間 0–長度）：片段是一段色條、色塊是黑或白；**拖片段左右＝改它在版型裡的開始時間**；「＋ 在這裡插入色塊」＝在播放頭把片段切開、中間插入 1 秒色塊（後面的往後、超出版型長度的截掉）；修剪用 G3 的旗標。
   - 剪輯分頁對版型：分割、刪除、複製、變速（整個版型的時間）、修剪（版型長度）。點了格子聚焦時，剪輯分頁的「修剪」＝那一格的片段軸。
4. **時間軸**：版型是**一個片段**（縮圖用第 1 格），長按拖移、修剪都是整個版型。

### 舊版型轉換（v2 → v3）
- `migrateProject`：找出同一個 `group` 的外框（鎖住）＋格子物件 → 換成一個 `TemplateItem` 放在外框原本的軌道；格子的 `cell` → `rect`（從畫面座標換成版型座標，外框滿版時就是同一個值），`trimIn`、`duration` → 一個 `CellClip`；格子原本的軌道空了就刪掉。`version: 3`。
- 單元測試：拍貼機直條 4 格、膠卷橫向、九宮格各轉一次，畫面（`buildScene` 的方框）跟轉換前一樣。

### 驗收
- 單元：版型方框換算（scale 0.5、旋轉 90° 時格子位置）；`fill` 色塊時段；drift／slide 位移；轉換。
- e2e：加膠卷直向（3 格）→ 時間軸只有 1 個片段；預覽雙指縮小 → 外框和 3 格一起變小（取樣格子中心顏色仍是對的素材）；點格子不會單獨縮放；聚焦格子 → 片段軸出現 → 拖旗標改片段 → 那一格畫面改變；格子素材比版型短 → 後段是黑色（取樣）、改成白色；插入色塊；動畫「捲動」：開頭與結尾外框位置不同；舊專案（測試寫 v2 JSON）打開後變成 1 個版型物件、畫面一樣。
- 要改的既有 e2e：`layout.spec`（整個重寫：「點預覽選到格子」→「點預覽選到整個版型」）、`crop.spec` 的格子裁切。

## G5. 特效分頁：轉場（使用者＊特效）
- 新分頁「特效」（第 8 個，放在「素材」後面；分頁列本來就可以左右滑）。
- 轉場放在**同一條影像軌上兩個相鄰片段之間**（前一段結尾＝後一段開頭，誤差 0.05 秒內）。時間軸上兩段之間出現小方塊「⧉」，點了選轉場；也可以在特效分頁選了轉場後「套用到全部片段之間」。
- 轉場種類（第一批）：無、淡入淡出（交叉溶解）、黑場、**白閃**、**閃光（暖色漏光）**、左推、上推、縮放。長度 0.2–1.5 秒（預設 0.5）。
- 資料：`VideoItem.transitionIn?: { kind, duration }`（記在後一段）。畫面：兩段在轉場時間內都畫（前一段多畫 duration/2、後一段提早 duration/2，素材不夠就停在最後一格），用 alpha／位移混合；白閃、閃光是在上面多一層全畫面顏色／漸層，透明度曲線 0→1→0。
- 「閃光（暖色漏光）」：橘黃色徑向漸層從畫面一角掃過，`screen` 混合，中段過曝到接近白色——對應使用者截圖 ⑨⑩ 的效果；用程式畫的漸層，**不放任何第三方素材**。
- 驗收：單元（轉場時間內兩段的 alpha）；e2e（兩段之間套白閃 → 轉場中間取樣接近白、前後是原本的顏色；匯出一致）。
- 之後同一個分頁再放「濾鏡／調色」（關鍵影格規劃的 K6）。

## G6. 動態模板「三格故事」（使用者 7）
**我們自己設計的模板，不照抄截圖裡的模板**（字、構圖、時間都自己定；不用「NOVEMBER」字樣當預設，預設標題用目前月份的英文，例如專案建立在 11 月就是「NOVEMBER」，使用者可以改字）。

### 使用流程
版型分頁 → 新的分類「動態模板」→「三格故事」→ 選 4 支影片／照片（1 支開場、3 支三格）→ 輸入標題（預設月份英文）→ 一次做好，時間軸上是**一個版型物件**（G4 的 `TemplateItem`，加 `animation: 'story3'`）。

### 時間表（總長 8 秒，可以整體加長）
| 時間 | 畫面 |
|---|---|
| 0.0–1.6 秒 | 開場影片在畫面中間，16:9 大小（上下黑邊） |
| 1.6–2.2 秒 | 開場影片上下邊界往外推，變成滿版（遮罩動畫） |
| 2.2–2.8 秒 | 第 1 格從上面滑進來、佔上 1/3（開場影片被推到下面、淡出） |
| 2.8–3.4 秒 | 第 2 格從右邊滑進中間 1/3 |
| 3.4–4.0 秒 | 第 3 格從下面滑進下 1/3 |
| 3.4–6.4 秒 | 標題在正中間：大字每 0.18 秒換一種字體（用已下載的字體裡挑 5 種：襯線、粗黑、手寫、圓體、做舊），最後停在第一種；下面一行小的手寫字（副標，可改） |
| 6.4–7.4 秒 | 整個畫面漸漸染成暖橘色（色彩疊加，`multiply`＋亮度提高） |
| 7.4–8.0 秒 | G5 的「閃光（暖色漏光）」轉場到下一段 |

### 做法
- 動畫是**模板內建的函式**（像 VideoClip_2 的 `layoutMotion`），不是使用者的關鍵影格：`templateFrame(item, localT)` 回傳每一格的方框、遮罩、透明度、標題的字體 index 與透明度、整體色彩疊加。`buildScene` 呼叫它。
- 標題：模板物件裡有 `title: { text, subtitle, fonts: string[] }`，畫的時候用現有的 `renderText`（字體換的時候換 `fontId`）；字體沒下載的就跳過。
- 也可以在「素材」分頁放一個**動態標題貼圖**「字體輪播」：單獨的字卡加 `fontCycle: { fonts, interval }`，任何影片上都能用（同一個繪製函式）。

### 驗收
- 單元：`templateFrame` 在各時間點的格子位置、字體 index；字體輪播。
- e2e：做一個三格故事 → 時間軸 1 個物件、長 8 秒；0.5 秒取樣中間是開場影片、上下黑邊；3.6 秒三格都有；標題在 3.5 秒和 3.7 秒的字體不同（比對字卡渲染的雜湊）；7.7 秒畫面偏白（閃光）；匯出長度 8 秒。
- 🔴 iPhone：同時 4 支影片解碼（開場＋三格）的順暢度；字體輪播要先下載那幾套字體。

## 4. 實作備註（跟上面規劃不同的地方，2026-11-12 做完 G1–G6 後補）
- **G4 沒有做 `TemplateItem` 單一物件**，改成「一組物件＋group 語意」：每一格仍是普通影片物件（各自一條軌道，`groupRole:'cell'`、時間軸上藏起來），外框是一個物件（`groupRole:'frame'`，代表整個版型）。理由：裁切、修剪、音量、匯出、復原都直接沿用，不用寫第二套。整組變形＝`setTransform` 對版型內任何物件都轉成「整組」變形（`engine/groupTransform.ts`）。舊專案用 `markLegacyGroups` 補標記，不用升 `Project.version`。
- G4 沒做「素材中某幾秒轉色塊穿插」的專用介面：用修剪多段（G3）拆成多個片段，中間的空位會自動顯示色塊（反黑／反白）。
- G4 動畫進行中預覽上的選取框不跟著位移（選取框用靜止位置）；編輯位置請先設成「不動」。
- **G5 轉場的小圓圈做在 G5**（G2 留下來的項目）；轉場是「以接縫為中心、不需要前一段多出素材」的做法，推／升因此是「先滑出再滑進」。
- **G6 沒有另做模板物件**：用 G4 的 group（透明外框＋4 個動態格子）＋ G5 的顏色層（暖色、白閃）。新增資料：`VideoItem.cellAnim`（格子範圍隨時間滑動／撐開）、`VideoItem.template:'story3'`、`TextItem.fontCycle`、`TextItem.group`（標題、副標跟著模板移動／拿掉）。標題與副標是普通字卡，不跟著整組縮放（要縮放請在預覽上點它們）。
- 沒做：獨立的「字體輪播」貼圖（`fontCycle` 資料已經支援，之後在素材分頁放一個即可）；`docs/LAYOUTS.md` 沒有改寫（見 PROGRESS 日誌 G4/G6 的說明為準）。
