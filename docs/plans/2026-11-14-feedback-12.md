- 使用者：「可以針對不同機型調整畫面比例，但版型不要跑版（例如文字不要從一列擠到兩列）」；確認做法：「所有按鈕、分頁、卡片文字都不換行；一列放不下就**縮小頁面文字**（一樣統一大小，字的間距也要對應調整，不要多出很多空的空間），或**縮小按鈕的留白**（但字不要碰到邊框）。」

- 驗收：e2e 用四種寬度跑一次「每個分頁打開＋每種視窗打開」：320（iPhone SE 1 代）、375（SE 2／3、mini）、390（iPhone 13～15）、430（Pro Max）：

## X3. 裁切重做（第 4、5、6、7 點）

### 現況
- 裁切在預覽上做（`CropOverlay`＋`cropStore`），下面剪輯分頁有 `CropPanel`（比例）。預覽上的工具列：自由形狀、筆刷、橡皮擦、重設、取消、完成。
- 資料：`crop`（四邊）＋`mask`（自由形狀多邊形）＋點陣圖遮罩（筆刷／橡皮擦，`maskCanvas`，按下筆刷時從目前的四邊／形狀轉成點陣圖再畫）。所以現在筆刷是「建立在一般／自由裁切的結果上」。

### 新的模型：四個工具獨立、可以一起用
- 編輯中的狀態（`CropSession`）改成：
  - `crop`（一般裁切的四邊）、`mask`（自由裁切的多邊形）：照舊。
  - `strokes: Stroke[]`：**向量筆畫清單**，`{ mode: 'keep' | 'erase', w: number, pts: [x, y][] }`，座標是**整張原始畫面的 0～1**（跟縮放、平移無關）。
- 最後保留的範圍（依序算）：
  1. 底：有用一般或自由裁切（`crop` 不是全畫面或有 `mask`）→ 底＝四邊 ∩ 多邊形；**都沒用、但有筆刷筆畫** → 底＝空的（只留刷到的）；什麼都沒用 → 底＝整張。
  2. 照順序套筆畫：筆刷（keep）把刷到的加回來、橡皮擦（erase）把刷到的去掉；後畫的蓋過先畫的。
- 這樣：只用筆刷＝只留刷到的；只用橡皮擦＝整張扣掉擦的；先一般裁切再用筆刷＝框內＋刷到的；之後再拉四邊，筆畫不會不見。
- 存檔：完成時把上面的結果畫成點陣圖遮罩（沿用現有的點陣圖遮罩存法與「切完不跳」的 `maskBounds`），**另外把 `crop`／`mask`／`strokes` 存進物件**（新欄位 `VideoItem.cropEdit?: { crop; mask; strokes }`），下次進裁切能接著改（不會變成一整塊點陣圖改不動）。舊專案沒有 `cropEdit` → 用現有的 crop／mask／點陣圖開始（點陣圖當成「底」）。

### 介面（預覽上）
- 右上角：❌ 圓鈕（取消，這次裁切都不存），跟 X2 一樣的樣式。
- 第一列（工具，一列放得下，放不下可以左右滑，不換行）：**一般裁切｜自由裁切｜筆刷｜橡皮擦**（segmented，選中主題色）。一般裁切＝拖四邊四角；自由裁切＝畫一圈；筆刷／橡皮擦＝刷。
- 第二列：**↩ 復原｜↪ 重做｜檢查結果｜套用裁切**（套用＝`btn primary` 主題色）。「重設」拿掉（要重來：按 ❌ 再進裁切，或一直 ↩）。
  - ↩↪：整個裁切的每一步都算（拉四邊放手一次、畫一圈、每一筆畫），`CropSession.history` 存 `{crop, mask, strokes}` 快照（筆畫只存參考，不複製點陣圖），最多 50 步。
  - 「檢查結果」：按住（或按一下切換）時，預覽只顯示保留下來的樣子（不顯示紅色提示、把手），讓人看結果。
- 筆刷／橡皮擦時第三列：粗細、距離滑桿（照舊）。
- 下面剪輯分頁的 `CropPanel`：比例 chips 照舊（只影響一般裁切）。

## X7. 轉場時的聲音（使用者補充 11-14）
- 使用者原話：「在轉場中過渡期時會沒有音效，我覺得這個音效應該是自行調整要不要，而不是我調整轉場的起迄時間，這段期間都沒有聲音；有些只是過渡期，還是需要有原音的。」
- 注意：使用者可能是在 VideoClip_2 上看到的；VideoClip 的現況要先確認（下面）。不管哪邊，**VideoClip 的轉場聲音現在不能調**，這次要補。

### 現況（讀程式找到的）
- `engine/transitions.ts` 的 `activeTransition`：接縫**前**半段 A 是真的（有聲音）、B 是提前出現的虛擬物件（`silent()`，音量 0）；接縫**後**半段 B 是真的、A 是延長的虛擬物件（音量 0）。所以理論上是「到接縫一刀切換」，不是整段沒聲音；但是：
  - **完全不能選**：沒有交叉淡化、也不能選只要某一段。
  - **iPhone 可能真的整段沒聲音**：沒有 `navigator.audioSession` 的 iPhone 走 `element` 模式（`audio.ts` 的 `elementAudioState`），音量 0＝`muted=true`；B 在暖機（`WARM_S`）時是**靜音狀態下被 `play()`**、接縫後才把 `muted` 改成 false——iOS 上「不是在使用者點擊當下」把靜音中的影片改成有聲，常被擋（影片被暫停或維持沒聲音）。A 延長的那段同理。這要真機確認（見最後的量測）。
  - **匯出**（`exporter.mixAudio`）：每個物件只放自己 `[start, start+duration]` 的聲音 → 也是到接縫一刀切，不會交叉淡化。

### 做法
- **資料**：轉場加 `TransitionIn.audio?: 'cross' | 'cut' | 'custom' | 'prev' | 'next' | 'mute'`，沒寫＝`'cross'`（交叉淡化）；`'cut'` 另存 `audioCut?: number`（切換點，轉場進度 0～1，預設＝接縫的位置 `before / (before + after)`）。
- **純函式** `transitionGains(mode, p)`（`engine/transitions.ts`，`p`＝整段轉場的進度 0～1）→ `{ a, b }`：
  - `cross`：等功率交叉淡化 `a = cos(p·π/2)`、`b = sin(p·π/2)`（中間兩段都聽得到、總音量不會掉）。
  - `prev`：轉場期間只有前一段（`a = 1`、`b = 0`），轉場結束才換後一段。
  - `next`：轉場一開始就換後一段（`a = 0`、`b = 1`）。
  - `cut`（**直接切換，不淡化**；使用者補充：「左推這類推拉轉場，我要自己決定哪個時間直接換成那一段的聲音」）：`p < audioCut` → `a = 1, b = 0`；之後 → `a = 0, b = 1`。兩段聲音都是原本的音量、沒有淡入淡出，只是在使用者選的那一刻一刀切。
  - `custom`（**自訂起迄**；使用者補充：「要有播放軸和標記，第一個影片標記聲音『迄』、第二個影片標記聲音『起』；可以等影片完全推進來、或正式停住之後才放它的聲音」）：另存 `audioOutA?: number`（前一段的聲音在哪裡停，相對接縫的秒數，可負）、`audioInB?: number`（後一段的聲音從哪裡開始，相對接縫的秒數，可以到轉場結束之後）。`t < cut + audioOutA` → `a = 1`，否則 0；`t ≥ cut + audioInB` → `b = 1`，否則 0。兩個標記中間有空隙＝那段沒聲音；重疊＝兩段一起出聲（都是原音量、不淡化）。範圍：`audioOutA` 在「轉場開始」～「前一段畫面最後出現的時間」之間；`audioInB` 在「轉場開始」～「後一段結束」之間（可以等轉場完全結束、畫面停住之後才開始出聲）。`custom` 的 `audioInB` 超過轉場結束時，**轉場結束後的那一段 B 也要套用**（不是只有轉場期間），所以增益判斷放在 `Player.syncVideo`／匯出的 B 物件上，不只在 `activeTransition` 裡。
  - `mute`：轉場期間都沒聲音（`a = b = 0`，給想要「停一下」的人）。
- `activeTransition`：不要再用 `silent()` 把虛擬物件設 0；改成真的、虛擬的都設 `volume = 原音量 × 增益`（A 用 `a`、B 用 `b`）。虛擬物件照舊拿掉自己的淡入淡出（避免重複）。真的那個保留自己的淡入淡出再乘上增益。
  - 素材不夠的地方本來就沒聲音可放：A 在出點之後沒有素材（停在最後一格）→ 那段 A 沒聲音；B 入點之前沒有素材（停在第一格）→ 那段 B 沒聲音。這是素材的限制，在設定視窗提示（下面）。
- **iPhone 不要靠切換 `muted`**：
  - `webaudio` 模式（有 `audioSession`）：元素一律 `muted=false`、音量用 GainNode（現在就是）→ 交叉淡化直接可用。
  - `element` 模式（舊 iPhone）：要出聲的元素在**使用者按播放的那一下**就全部 `muted=false`、`play()`（含預載的下一段：`Player.play()` 時把 `upcoming` 的 B 也 unmute＋play 再 pause，取得許可）；之後轉場期間只能「開／關」（iOS 忽略 volume）→ `cross` 在這個模式退化成「接縫一刀切」（`a ≥ b` 的那一段出聲），在設定視窗寫「這支手機的瀏覽器不支援聲音淡入淡出，會在接縫切換」。
- **匯出一致**（`exporter.mixAudio`）：有轉場的接縫，A 多放 `[end, end + after]`、B 多放 `[start − before, start]` 的聲音（各自只放素材有的部分），並在各自的 GainNode 後面再串一個「轉場增益」節點，用 `setValueCurveAtTime` 畫 `transitionGains` 的曲線（取 32 點）。
- **介面**：轉場的時間設定視窗（`EffectTimingSheet`，接縫那種）加一區「轉場時的聲音」：**交叉淡化／直接切換／自訂起迄／只要前段／只要後段／靜音**（radio，名稱簡短，預設交叉淡化）。選「自訂起迄」→ 打開「轉場聲音起迄」視窗（`TransitionAudioSheet`，跟片段範圍同樣的樣子）：上面是**專案畫面**的預覽（這一刻轉場的樣子）、▶（有聲音，照目前標記播轉場前後各 1 秒）↩↪；下面一條縮圖軸＝前一段的尾巴接後一段的開頭（接縫畫一條直線、轉場範圍淡色底）；兩個標記旗標：**「前段 聲音迄」**（前一段的顏色）、**「後段 聲音起」**（後一段的顏色），可以拖；白線＝目前時間；下面一行字「前段聲音到接縫前 0.20 秒停、後段聲音從轉場結束後 0.30 秒開始，中間 0.8 秒沒有聲音」；最下面「套用」，右上 ❌。選「直接切換」時，下面多一條「聲音切換時間」：在這個視窗的轉場預覽／時間條上用一條小旗標拖（顯示「接縫前 0.3 秒」這種字），預設在接縫。下面小字依素材情況提示：「前一段在接縫後沒有多的畫面，這段只聽得到後一段」等。單一素材的進場／出場特效不影響聲音（照常播放），在特效分頁說明一行。
- **量測（真機）**：效能框的「最近轉場」那行加「聲音 A 增益／B 增益、B 元素 muted／paused」，請使用者在 iPhone 播一次轉場後截圖，確認轉場中真的有聲音。

### 驗收（X7）

## X8. 畫畫（使用者補充 11-14）
- 使用者原話：「畫畫功能可以加在這（素材分頁，現在寫著『畫畫功能之後會加在這裡』）；畫畫可以選擇要動畫、或是畫畫的最終作品直接呈現；動畫可以是記錄我在影片中畫畫的過程（畫畫順序等等，用描繪的感覺）。」——就是 `docs/PLAN.md` 的 Phase 5／R15。
- 參考：VideoClip_2 的 `DrawingEditor.tsx`（在彈窗裡畫、存成一張圖片素材，**沒有動畫**）、`engine/brushDynamics.ts`（筆畫點帶壓力與毫秒時間）、`engine/pencilBrush.ts`（鉛筆紙紋）。只參考，程式自己寫；VideoClip 要能重播，所以**筆畫存向量、不存成圖片**。

### 資料
- 選項名稱一律**簡短直觀**（使用者重申）：工具「畫筆／麥克筆／鉛筆／螢光筆／橡皮擦」、顯示方式「完成圖／動畫」、儲存位置「這個專案／這台手機」。
- 新物件類型 `DrawingItem`（放在影像類的軌道，跟貼圖一樣可以移動、縮放、旋轉、透明度、定格、特效、色調）：
  - `strokes: { tool: 'pen' | 'marker' | 'pencil' | 'highlighter' | 'eraser'; color: string; size: number; opacity: number; pts: [x, y, pressure, ms][] }[]`——座標是畫畫時「版面」的 0～1；`ms`＝從開始畫起的毫秒（記錄畫的順序與快慢）。
  - `show: 'final' | 'replay'`：直接顯示完成的畫／動畫重播畫的過程。
  - `replayDuration: number`：重播要花幾秒（預設＝實際畫的時間，最少 0.5、最多 10 秒；可以調）；重播完停在完成的畫，一直到物件結束。
  - 預設長度 3 秒、從播放頭開始；`transform` 預設滿版置中（畫的時候就是滿版）。
- 點太多時存檔前簡化（Ramer–Douglas–Peucker，誤差 0.5px），一筆最多 2000 點。

### 畫的介面
- 素材分頁「＋ 畫畫」→ 預覽進入畫畫模式（跟裁切一樣在預覽上做，暫停在播放頭這一格當底圖）：
  - 右上 ❌（不存）；**儲存鈕**（💾「儲存」，使用者補充）：把這幅畫存成素材，按了跳出二選一「存在這個專案／存到這台手機（之後其他專案也能用）」——存到手機＝放進「我的素材庫」（現在存貼圖的地方，新增 `kind: 'drawing'`，存向量筆畫＋縮圖，不存成圖片，才能保留動畫）；存在專案＝放進專案的素材清單。儲存後留在畫畫模式可以繼續畫；之後素材分頁「我的畫」清單點一下就能加到時間軸。第一列工具：畫筆／麥克筆／鉛筆／螢光筆／橡皮擦（橡皮擦擦的是筆畫，也是一筆 `eraser`，重播時也看得到在擦）；第二列：顏色（`ColorPicker` 常用色＋最近用過）、粗細、透明度；第三列：↩ ↪ ｜「顯示：完成圖／動畫」｜**完成**（主題色）。
  - 可以放大縮小精細畫（跟 X3 裁切同一套 `.crop-zoom` 做法，兩指縮放平移、一指畫）。
  - 畫的時候只在 overlay canvas 增量畫，不重畫預覽（同 X3 的「不閃」規則）。
- 再點一次畫畫物件 → 素材分頁顯示「編輯這幅畫」（回到畫畫模式接著畫）、顯示方式、重播秒數滑桿、「從頭重播一次」試看。

### 畫出來（預覽與匯出一樣）
- 新 `engine/drawingRender.ts`：`renderDrawing(item, local, ctx, w, h)`。
  - `final`：全部筆畫畫一次，結果快取成一張 canvas（筆畫沒變就不重畫），當成一般圖片圖層送合成器。
  - `replay`：把筆畫的 `ms` 等比壓到 `replayDuration`，在物件開始後 `local` 秒時：已經畫完的筆畫用快取的那張（每畫完一筆才更新快取一次）、正在畫的那一筆只畫到這一刻的點（描繪感），筆畫之間的停頓照比例保留。每格只多畫「目前那一筆的一段」，不會每格從頭畫。
  - 筆刷外觀：畫筆＝圓頭實線；麥克筆＝平頭、略透明；鉛筆＝細、有紙紋（參考 `pencilBrush` 的做法）；螢光筆＝寬、`multiply` 疊色、半透明；壓力（iPhone 手指沒有壓力就用速度）微調粗細。
- `scene.ts` 新增 drawing 圖層 → `compositor` 用 canvas texture；`exportFrame`／`exporter` 走同一個函式。

### 驗收（X8）
- 單元：`renderDrawing` 重播進度——一筆 1 秒、一筆 1 秒、中間停 1 秒、`replayDuration` 3 秒：1.5 秒時第一筆完成、第二筆還沒開始；2.5 秒時第二筆畫一半；3 秒後全部完成；`final` 任何時間都是全部；RDP 簡化後點數變少、端點不變。
- e2e：素材分頁 → 畫畫 → 用 `touchDrag` 畫一條紅色橫線、一條藍色直線 → 完成 → 時間軸多一個畫畫片段；`final`：物件開始那一刻兩條線都在（預覽與單格輸出取樣）；切成「動畫」、重播 2 秒：0.5 秒時只有紅線的一部分、1.9 秒時紅線完整＋藍線一部分、2.5 秒時兩條都完整；橡皮擦擦掉紅線中間 → 重播最後中間是空的；❌ 不存；畫的過程中預覽 canvas 的像素 hash 不變（不閃）。
- **刪除**（使用者補充）：素材分頁「我的畫」（這台手機）和「這個專案的畫」清單，每一幅右上角有 ⋯ → 「刪除」（跳確認「刪除後不能復原；已經放進影片裡的不受影響」）；刪除只拿掉素材庫裡的那一份，**已經加到時間軸的畫是複本，不會跟著不見**。
- 儲存：畫完按「儲存」→「存到這台手機」→ 開另一個專案，素材分頁「我的畫」有這幅、加進去後重播動畫正確；「存在這個專案」→ 只有這個專案看得到。
- 刪除：「我的畫」刪除一幅 → 清單少一幅、重新整理後也沒有；已經加到時間軸的那幅還在、能播。
- 效能：有一幅 50 筆的動畫畫畫播放 2 秒，fps 跟沒有畫畫差 < 15%。
