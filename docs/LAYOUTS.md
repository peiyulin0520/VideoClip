# 多格影片模板規格（R22：拍貼機、膠卷…）

> 使用者 2026-11-11：「希望還可以增加不同模板，例如拍貼機或膠卷，可以有多格影片呈現在不同格子裡面，然後可以以特效方式滑過等」
> 狀態：**L1（靜態版型）已實作**（2026-11-12，使用者說「先做多格模板」）；L2 物件動畫核心、L3 版型動畫（閃白、膠卷捲動、依序滑入）還沒做。
> **L2／L3 的規劃已寫好**：`docs/plans/2026-11-12-keyframes-film.md`（使用者給了剪映膠卷特效教學：用關鍵影格讓影片往上捲過畫面＋底片框）。
> 長相是我自己設計的（沒有參考圖）——截圖在 `docs/screenshots/feedback-5/layout/`，請使用者看過後提出要改的地方（`AGENTS.md` 規則 4）。
>
> **L1 實作方式（跟下面 §3 原本的設想不同，比較簡單）**：版型＝一張**外框 PNG**（有色的外框，格子是透明的洞；`engine/layouts.ts` `paintFrame`／`renderFramePng`，大小跟專案畫面一樣）放在最上層（**鎖住的軌道**，所以點預覽點得到下面的格子）＋每一格一個**普通的疊加影片／照片**（`cellItem`：素材置中裁成格子的比例，方框剛好等於那個洞）。沒有新的物件種類；格子可以個別選取、裁切、換素材、調音量。`VideoItem.cell`＝這格的位置，`VideoItem.group`＝同一個版型共用的 id（「移除版型」用）。裁切模式對格子預設鎖定格子比例，完成後畫面仍填滿格子（`cellTransform`）。
> 已做的 8 個版型：拍貼機直條（4 格）、拍貼機 2×2、膠卷橫向、膠卷直向、拍立得、上下雙格、三格、九宮格；外框顏色 白／黑／粉／奶茶；畫面很寬或接近正方形時整個版型縮小放得下（`fitInCanvas`）。
> **沒做／限制**：整個版型一起移動／縮放／旋轉（要個別調整每一格）；格子之間的動畫；在格子上直接雙指縮放（用「裁切」調範圍）；改畫面比例後外框不會跟著重畫（要刪掉重做）；空格子（要先選好素材才能做版型）；同時播放超過 5 支影片會提醒。

## 1. 使用者看到的樣子

- 疊加分頁（或新的「版型」分頁）有一排**版型縮圖**：拍貼機直條、拍貼機 2×2、膠卷橫向、膠卷直向、拍立得、上下雙格、三格、九宮格…
- 點一個版型 → 放在目前這一秒，畫面上出現「外框＋空格子」（空格顯示「＋ 點這裡放影片」）。
- **點格子 → 選影片或照片**（從相簿或本專案已匯入的素材），影片自動填滿格子。
- 選中某一格時，用手指在格子裡**拖動／雙指縮放**，調整影片在格子裡露出的範圍（就像 IG 限動的拼貼）；格子本身不動。
- 整個版型可以像一般物件一樣移動、縮放、旋轉、調整出現時間與長度。
- 每格可以各自設定「從影片的第幾秒開始」，也可以設定格子依序出現。
- **動畫（特效方式滑過）**：版型可選一種動畫，例如
  - 拍貼機：一格一格「喀擦」閃白出現（像拍照）、或整條從下往上滑出（像機器吐出照片）。
  - 膠卷：整條底片持續往左／往上**捲動**（跑馬燈），格子一格一格滑過畫面。
  - 通用：格子依序滑入（左右上下）、縮放彈出、翻頁。
- 外框可換顏色（白、黑、粉、奶茶…），可在下方空白處寫字（日期、標題）——直接用現有的字卡疊上去。

## 3. 技術做法（建議）

**版型 = 一群普通圖層＋一個外框圖層，用 `groupId` 綁在一起**（不新增一種很特別的物件），好處是預覽、匯出、圖層屬性、選取、儲存都沿用現有程式。

1. **資料**（`src/model/types.ts`）
   - 新物件型別 `FrameItem`（`type: 'frame'`）：版型的外框與格子位置，畫法跟字塊一樣用路徑（`engine/layouts.ts`：每個版型是一個函式 `(params) → { frame: Op[], cells: Rect[] }`，座標用 0–1 比例）。參數：外框顏色、格子間距、圓角、底片齒孔顏色。
   - 每一格是一個普通的疊加影片／照片物件（`VideoItem`），加上 `groupId`（＝外框的 id）和 `cell: number`（第幾格）。格子的位置／大小由外框算出來，物件本身的 `crop`（已有）＋新增的格內平移縮放 `cellView: { x, y, scale }` 決定露出哪一塊。
   - 空格子：沒有物件，外框上畫「＋」提示（只在預覽畫，匯出不畫）。
2. **畫面**（`engine/scene.ts`、`compositor.ts`）
   - 格子用遮罩（現在圓角已經用 Graphics 遮罩）把影片裁成格子的形狀；外框畫在格子上面。
   - 群組一起移動／縮放／旋轉：選到群組任何一部分，預覽上的選取框框住整個外框；拖＝整組移動。點「編輯格子」或雙擊某格才進入格內調整模式。
3. **動畫**——需要 Phase 4 的「物件動畫」核心（`docs/EFFECTS.md` §2 片段進出場動畫）：
   - 先做通用的「物件進場／出場／循環動畫」（時間 → 位移、縮放、旋轉、透明度、遮罩位移），預覽與匯出共用。
   - 版型動畫是一組預設：拍貼機閃白＝每格依序 `flash`＋`fade`；膠卷捲動＝整組 `loop` 位移（條比畫面長，循環接回）；依序滑入＝每格 `slide-*` 加延遲。
4. **效能**：iPhone 同時解碼的影片數量有限（Phase 2 已列入真機驗證）。版型一次最多 **4 支影片**同時播放，其餘格子建議放照片；超過時提示。九宮格建議放照片。
5. **測試**：每個版型的格子位置單元測試（不重疊、在外框內）；e2e：選版型 → 每格放影片 → 預覽與單格匯出取樣顏色一致；動畫關鍵 3 格截圖對照。

## 4. 建議的實作順序

| 步驟 | 內容 | 可以先給使用者看的東西 |
|---|---|---|
| L0 | **先給使用者看 8 個版型的靜態草圖**（一張總覽圖），或請使用者提供喜歡的拍貼機／膠卷參考圖 | 版型總覽圖 |
| L1 | 靜態版型：外框＋格子＋把影片放進格子＋格內調整＋整組移動縮放 | 拍貼機、膠卷、拍立得實際放影片的截圖 |
| L2 | 物件動畫核心（Phase 4 §2，字卡動畫也會用到） | 進場動畫關鍵格 |
| L3 | 版型動畫預設：閃白、膠卷捲動、依序滑入 | 動畫關鍵 3 格對照、匯出影片片段 |

L2 是 Phase 4 的一部分，做完也讓一般影片、貼圖、字卡都有進出場動畫。
